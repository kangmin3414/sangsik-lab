# 제로의 편지 · 쇼츠 기획 (50초, 2026-11-01)

재료: `SCRIPT_v4.md`(인정받고 싶은 마음, 네 사람의 자리). 화풍: 스틱맨 + 수채화, **세로 9:16**. 목소리: 미정(추천 Schedar).

## 한 줄 콘셉트

불 꺼진 아파트에서 **창문 네 개가 하나씩 켜지며** 각자의 자리에서 아무도 알아주지 않은 하루가 한 줄씩 나오고, 마지막 창문에서 편지를 쓰던 제로의 비밀이 드러난 뒤, **처음의 꺼진 센서등이 다시 켜지며** 첫 장면으로 이어진다(무한 반복).

## 감동의 짜임

1. **나도 못 들었다** (질문) → 2. **저 사람도, 저 사람도** (네 창문) → 3. **다들 같은 걸 바란다** (건물 전체) → 4. **편지 쓴 사람도 그랬다** (반전) → 5. **그래도 없던 일이 되진 않는다** (불이 켜짐).

위로의 말("잘하고 있어", "수고했어")은 끝까지 직접 하지 않는다. 마지막 한 줄은 사실만 말한다: "아무도 몰라줘도, 없던 일이 되진 않아요."
