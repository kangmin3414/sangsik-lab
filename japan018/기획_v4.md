# 실험 018 · 만약에 한국 사람이 일본에서 30년을 산다면? (기획 v4 — 그림책 다큐 형식, 2026-10-30)

> v4 변경(운영자 요청): **퀄리티 좋은 그림과 내레이션이 함께 어우러지는 구성.**
> 이야기(1·5·10년은 '몰랐던 일본'이 깊어지고, 30년 차엔 일본 사람이 된 눈으로 한국을 본다)는 v3 그대로.
> 바뀌는 것: **화면의 주인공이 SVG 애니메이션 → 한 장 한 장 그린 일러스트(약 50장)**, 내레이션 중심의 다큐 호흡.

## 1. 형식 한눈에
- **그림책 다큐**: 내레이션 한두 문장마다 그림 한 장. 그림은 천천히 밀고 당기는 카메라(켄 번스), 빛·눈·꽃잎 같은 가벼운 움직임, 그 위에 작은 자막 라벨.
- 그림: Nano Banana 2.1 (Google Cloud, **무료 크레딧만**), 16:9 2K. 013 엄마 편 '이야기 그림'과 같은 방식·같은 파이프라인(`make_ai.py` + `ai018.js` 레이어)을 키워서 쓴다.
- SVG는 **장(章) 카드, 수심 HUD, 라벨·인용 카드, 해저 비유**에만. 인물 장면은 모두 그림.
- 목소리: Gemini TTS. **내레이터가 이끌고**, 인물 대사는 짧게(일본어 3~4마디, 엄마·조카·하나 몇 줄).

## 2. 비주얼 방향
### 스타일 (추천: 채널 캐릭터 유지)
- 인물: 채널의 **둥근 흰 머리 캐릭터 스타일**(013 그림처럼) — 제로가 누군지 바로 알아보게.
- 배경: 그림책처럼 결이 살아 있는 회화풍, 부드러운 햇빛, 따뜻한 색. **항상 밝게**(017 교훈: 어둡고 칙칙한 배경 금지 — 밤 장면도 등불·노을빛으로 따뜻하게).
- 그림 속 글자 금지(간판·회람판·메뉴판은 무늬로만) → 필요한 글자는 우리가 위에 라벨로 얹는다(AI가 일본어·한글을 틀리게 그리는 문제 방지).
- 아래 1/5은 단순한 바닥·탁자 면(자막 자리).

|---|---|---|---|

### 같은 자리, 다른 시간 (반복 구도 — 그림과 내레이션이 맞물리는 핵심 장치)
- **아파트 쓰레기장, 아침 7시**: 1년 차(야마다 씨가 제로에게 분리 표) ↔ 30년 차(제로가 한국 청년에게 분리 표). 같은 구도, 같은 각도.
- **동네 골목 한 길**: 장마다 한 번씩. 간판·자전거·나무 크기·계절이 바뀌고, 제로의 나이도 바뀐다.
- **식당 두 곳**: 도쿄 정식집(조용, 반찬 없음) ↔ 서울 백반집(이모, 반찬 가득). 같은 구도로 나란히.
- **제로의 방 창가**: 장 끝마다 한 장 — 창밖 계절만 바뀐다.

### 제로의 나이 (캐릭터 설정표를 먼저 만든다)
- 1년: 기본 제로(주황 티셔츠 대신 첫 출근 정장 셔츠 + 사원증)
- 5년: 얇은 안경
- 10년: 안경 + 넥타이 + 피곤한 눈
- 30년: 안경 + 짧은 회색 옆머리 + 카디건 + 접이식 장바구니(일본 사람 다 된 디테일)

### 등장인물 설정표 (SVG로 그려 참조 그림으로 씀)
제로(4개 나이), 야마다 씨(60대 이웃, 회색 머리·앞치마), 사토 과장(정장·안경), 하나(동료→친구, 단발), 엄마(한국, 영상통화), 여동생, 조카 민준(10대), 30년 차의 한국 청년, 박사님(영상통화 창 속).

## 3. 내레이션 방향
- **그림 한 장 = 한 호흡.** 그림이 바뀌는 순간 = 새 문장의 시작. 문장 안에서 그림을 바꾸지 않는다.
- 그림이 말하게 두고 설명은 줄인다: "보이는 것"은 말하지 않고 "보이지 않는 것(마음·이유·연구)"을 말한다.
- 장마다 끝은 짧은 쉼(1~1.5초) + 창가 그림 + 음악.
- 내레이터 톤: 따뜻한 다큐(지금 style38 Schedar 유지), 30년 차는 조금 더 느리게.
- 분량: 약 2,850자 · 80줄 안팎 · 8:30.
