특징 다섯 개 (이것만 지키면 제로)
  1. 가로가 조금 더 넓은 흰 동그란 머리, 굵은 검은 외곽선
  2. 이마 위로 올린 민트색 동그란 고글, 남색 끈
  3. 작은 검은 타원 눈 + 굵은 눈썹, 입은 선 하나
  4. 노란 민소매 실험 조끼, 가운데 지퍼, 가슴 ‘00’ 패치
  5. 막대 팔다리, 손가락 없는 흰 장갑 손, 흰 운동화
제작 시간을 줄이는 규칙
  • 손가락·옷 주름·명암은 그리지 않습니다
  • 표정은 눈썹부터 바꾸고, 입은 웬만하면 선 하나로
  • 움직임은 컷 전환 + 편집기 줌·흔들림으로 대신합니다
  • 배경만 장면마다 새로 만들고, 제로는 같은 시트를 참조합니다
  • 고글이 내려오면 ‘실험 시작’, 올라가면 ‘실험 끝’ 신호
