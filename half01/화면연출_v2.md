# '운명의 반쪽'을 찾느라 지치는 사람들 — 화면 연출 v2 (플라톤 『향연』 아리스토파네스)

화면 연출만. 각 묶음 위의 번호는 `대본_v2.md`의 줄 번호다. "대사 3번 뒤 → 4번 앞"은 3번 줄이 끝나고 4번 줄이 나오기 전부터 깔리는 화면이라는 뜻(다음 대사 동안 이어짐).

[영상 제목]
 * 추천: '운명의 반쪽'이라는 말을 처음 한 사람 | 플라톤 『향연』
 * A/B: 딱 맞는 사람을 찾느라 지친 당신에게, 2400년 전 술자리의 이야기
 * A/B: 내 반쪽은 왜 안 나타날까
[썸네일] 소개팅 테이블. 제로 배꼽에서 튀어나온 반달 모양 반쪽이가 상대를 향해 빨간 X 팻말을 들고, 제로는 당황. 뒤로 희미하게 반으로 갈라진 둥근 사람 실루엣. 글자: "범인은" / "배꼽 속에" (철학자 얼굴 없음)
[예상 러닝타임] 약 6분 30초 (말 약 1,600자 + 말 없는 장면)
[캐릭터]
 * 제로(주황 티, 서른넷 직장인): 이야기의 주인공. 꿈속에서 연회 손님이 되고, 신화 속 둥근 사람이 된다.
 * 반쪽이: 제로 배꼽에 사는 반달 모양 꼬마(손바닥만 함, 한쪽이 평평하게 잘린 공, 눈 둘, 짧은 팔다리). 처음엔 '반쪽 본'(자기 잘린 면과 같은 모양의 종이 본)과 빨간 X 팻말을 들고 다닌다. 4막부터 본 대신 작은 나침반. 내 안의 '딱 맞는 반쪽이 어딘가 있어'(피로사회 편 미니 코치 계열).
 * 친구(신랑): 인트로.
 * 소개팅 상대들: 회색 얼굴의 일반인 몽타주. 결말의 상대만 색이 있다(노란 머플러, 아침형).
 * 아리스토파네스: 희극 작가 스틱맨, 짧은 곱슬머리, 머리에 희극 가면. 딸꾹질할 때마다 몸이 들썩.
 * 에뤽시마코스(의사), 아가톤(월계관의 집주인 시인), 소크라테스(채널 기존 디자인).
 * 둥근 사람들: 공 모양 몸에 팔 넷·다리 넷·앞뒤 얼굴 둘. 세 색(해=주황, 땅=초록, 달=은색).
[연출 기준] 연출 기획서 v3 + 물리 점검표. 제로는 모든 막에 나온다(본 이야기 속 주인공). 고대 장면은 세피아 + 붉은 항아리 그림 색(검은 윤곽, 테라코타). 둥근 사람은 귀엽게, 성적인 묘사 없음. 신들은 얼굴을 가림.

## [00:00 ~ 00:50] 인트로: 배꼽에서 나온 녀석
- **첫 대사 앞**
  단풍 장식의 결혼식장. 신랑이 신부 손을 들어 보이며 활짝. 둘 사이에 하트 퍼즐 두 조각이 '딱' 맞는 그림.
- **대사 1번 뒤 → 2번 앞**
  하객석의 제로가 박수를 치다 멈칫. 축의금 봉투 세 장이 겹쳐 보이는 짧은 컷(9월·10월·11월 도장). 셔츠 단추 사이 배꼽이 반짝, 간질간질 효과선.
- **대사 2번 뒤 → 3번 앞**
  "뽕!" 배꼽에서 반달 모양 반쪽이가 튀어나와 제로 무릎 위에 착지. 제로 깜짝(눈 동그랗게). 반쪽이가 신랑 신부를 가리키며 발을 동동.
- **대사 3번 뒤 → 4번 앞**
  소개팅 카페. 제로와 상대가 마주 앉고, 테이블 위에 반쪽이가 당연하다는 듯 앉아 있다(상대에게는 안 보임).
- **대사 4번 뒤 → 5번 앞**
  몽타주 세 컷. 컷마다 반쪽이가 '반쪽 본'을 상대에게 대 보고 빨간 X 팻말: ①말이 빠른 사람 ②고양이 사진을 보여 주는 사람 ③"저 아침형이에요"라는 사람. 제로가 반쪽이 눈치를 보며 서둘러 계산서를 집는다.
- **대사 5번 뒤 → 6번 앞**
  헤어지는 길, 세 번째 상대가 아쉬운 얼굴로 돌아본다. 제로도 뒤돌아보려는데 반쪽이가 넥타이를 잡아끈다.
- **대사 6번 뒤 → 7번 앞**
  달력이 넘어가며 소개팅 X 표시가 쌓인다. 소파에 녹아내린 제로, 그 배 위에서 반쪽이가 쌍안경으로 창밖을 살핀다.
- **대사 7번 뒤 → 8번 앞**
  제로가 천장을 보며 한숨. 반쪽이는 여전히 쌍안경.
- **대사 8번 뒤 → 9번 앞**
  스포트라이트 + "범인" 딱지가 방 안을 훑다가 제로 배꼽 위에서 멈춘다. 반쪽이가 딴청(휘파람). 타이틀 [제로의 세계]. 두루마리 책 카드 『향연』 · 플라톤.

## [00:50 ~ 01:50] 1막: 딸꾹질하는 희극 작가
- **대사 9번 뒤 → 10번 앞**
  반쪽이가 제로 손가락을 잡고 배꼽 쪽으로 끌어당김.
- **대사 10번 뒤 → 11번 앞**
  배꼽이 소용돌이처럼 커지며 제로가 빨려 들어감(빙글빙글 추락). 세피아로 바뀌며 '쿵' 고대 연회장 소파 위에 떨어짐. 제로 옷은 주황 티 그대로, 옆 손님들은 토가 차림. 자막 라벨 "기원전 416년, 아테네".
- **대사 11번 뒤 → 12번 앞**
  월계관의 아가톤, 포도주 동이, 비스듬히 누운 손님들. 아리스토파네스가 일어서는데 "딸꾹!" 또 "딸꾹!" 의사 에뤽시마코스가 손가락 셋을 펴 처방(숨 참기 → 얼굴 빨개짐 / 가글 → 꼬르륵 / 셋째 손가락에서 멈춤).
- **대사 12번 뒤 → 13번 앞**
  제로가 소파 장식에서 깃털 하나를 뽑아 아리스토파네스 코끝을 살랑.
- **대사 13번 뒤 → 14번 앞**
  거대한 재채기. 등불이 흔들리고 아가톤 월계관이 날아감. 아리스토파네스가 제로 배꼽에서 고개를 내민 반쪽이를 보고 씩 웃음.
- **대사 14번 뒤 → 15번 앞**
  두루마리가 펼쳐지며 둥근 사람 그림이 살짝 보인다. 반쪽이가 두루마리 위로 기어올라 구경.

## [01:50 ~ 02:50] 2막: 반쪽이가 태어난 날
- **대사 15번 뒤 → 16번 앞**
  붉은 항아리 그림 화풍. 둥근 사람 하나가 '뿅'. 팔 넷, 다리 넷, 앞뒤 얼굴 둘이 동시에 손을 흔듦.
- **대사 16번 뒤 → 17번 앞**
  제로 몸이 둥글게 부풀며 둥근 사람이 된다. 앞얼굴은 제로, 뒷얼굴은 끝까지 보이지 않는 누군가(카메라가 돌면 늘 머리카락이나 그림자에 가림). 둘이 함께 데굴데굴 공중제비. 들판을 가로지르는 바퀴 행렬.
- **대사 17번 뒤 → 18번 앞**
  세 색의 둥근 사람들이 서로 올라타 탑을 쌓고 구름 위 올림포스로 굴러 올라감. 신전 기둥이 흔들림.
- **대사 18번 뒤 → 19번 앞**
  구름에 얼굴이 가린 제우스가 머리카락 한 올을 팽팽히 당겨 '스윽'. 옆에 비교 그림: 삶은 달걀이 머리카락에 잘림. 제로의 둥근 몸도 반으로 갈라지고, 뒷얼굴의 반쪽은 반대쪽으로 데굴데굴 멀어진다(얼굴은 끝내 안 보임). 제로가 손을 뻗음.
- **대사 19번 뒤 → 20번 앞**
  햇빛 역광의 아폴론(얼굴 안 보임)이 제로 얼굴을 잘린 쪽으로 빙글 돌려 주고, 배 가운데 살가죽을 주머니 끈처럼 '쪼옥' 오므려 묶는다. 매듭으로 줌인.
- **대사 20번 뒤 → 21번 앞**
  매듭 속에서 반달 모양 반쪽이가 '뽀록' 눈을 뜬다. 첫 숨. 두리번거리며 잃어버린 반쪽 쪽을 가리킨다.
- **대사 21번 뒤 → 22번 앞**
  들판의 반쪽들이 두리번두리번 서로를 찾는다. 짝을 찾은 둘이 와락 껴안음. 제로는 멀어진 반쪽 쪽을 바라보며 서 있다. 연회장으로 돌아와 아리스토파네스가 잔을 들고 마무리.

## [02:50 ~ 03:50] 3막: 반쪽이가 일으킨 사고
- **대사 22번 뒤 → 23번 앞**
  다시 신화 속. 화로 연기에 얼굴이 가린 대장장이 헤파이스토스가 망치를 들고 껴안은 연인들 앞에 선다. "붙여 줄까?" 말풍선.
- **대사 23번 뒤 → 24번 앞**
  반쪽이가 제로 배꼽에서 튀어나와 손을 번쩍번쩍. 반쪽이 손에 소개팅 상대 사진(98점 스티커). 제로가 "잠깐…" 말리기도 전에 사진 속 사람이 '펑' 옆에 나타난다(회색 얼굴의 일반인).
- **대사 24번 뒤 → 25번 앞**
  쾅쾅 용접 불꽃. 제로와 그 사람이 등을 맞댄 둥근 사람으로 붙는다. 걸으려 하면 다리 네 개가 각자 다른 방향 → '쿵' 넘어짐. 한쪽 배에서 꼬르륵, 다른 쪽은 하품.
- **대사 25번 뒤 → 26번 앞**
  제로가 화장실 표지판을 가리키는데 반대쪽 얼굴은 침대 쪽을 가리킴. 서로 끌어당기다 제자리에서 빙글빙글.
- **대사 26번 뒤 → 27번 앞**
  들판의 껴안은 반쪽들 위로 해가 여러 번 뜨고 지며, 실루엣이 하나둘 비쩍 마른다(무섭지 않게 짧게).
- **대사 27번 뒤 → 28번 앞**
  스포트라이트와 "범인" 딱지가 돌아와 반쪽이 머리에 '착'. 반쪽이가 반쪽 본으로 얼굴을 가린다.
- **대사 28번 뒤 → 29번 앞**
  인트로 소개팅 몽타주의 빨간 X 세 개가 다시 빠르게 지나감.

## [03:50 ~ 05:00] 4막: 반쪽이를 달래는 법
- **대사 29번 뒤 → 30번 앞**
  용접이 '퐁' 풀리며 둘이 떨어진다. 바닥에 주저앉은 제로가 반쪽이를 향해 처음으로 버럭.
- **대사 30번 뒤 → 31번 앞**
  반쪽이가 움찔, 반쪽 본을 떨어뜨린다. 작은 얼굴이 울먹. 잘린 면을 손으로 감싸 쥔다.
- **대사 31번 뒤 → 32번 앞**
  제로 버럭 → 멍 → 울먹. 정적 1초. 회상 플래시: 인트로 소개팅마다 나가기 전 현관에서 망설이던 제로의 등을, 반쪽이가 작은 손으로 밀어 주던 장면(같은 장면, 다른 시점).
- **대사 32번 뒤 → 33번 앞**
  연회장. 맨발의 소크라테스가 소파에서 몸을 일으키고, 아리스토파네스가 "또 시작이군" 표정. 제로가 반쪽이를 손바닥에 올려 함께 듣는다.
- **대사 33번 뒤 → 34번 앞**
  소크라테스 말풍선 속 회상: 베일을 쓴 여인 디오티마(얼굴은 베일 그늘)가 젊은 소크라테스에게 손가락을 세워 설명.
- **대사 34번 뒤 → 35번 앞**
  힌트 1 카드. 반쪽이 손의 반쪽 본이 '뿅' 작은 나침반으로 바뀐다. 나침반 바늘은 '딱 맞는 사람'이 아니라 해 뜨는 쪽을 가리킴. 두 사람이 같은 쪽을 향해 나란히 걷는 그림.
- **대사 35번 뒤 → 36번 앞**
  힌트 2 카드. 제로가 처음으로 자기 옆구리의 울퉁불퉁한 잘린 면을 내려다본다. 생각보다 들쭉날쭉.
- **대사 36번 뒤 → 37번 앞**
  제로가 피식 웃는다. 반쪽이도 따라 웃는다.
- **대사 37번 뒤 → 38번 앞**
  힌트 3 카드. 반쪽이가 배꼽으로 돌아가려다 고개만 쏙 내밀고 제로를 본다. 제로가 손가락으로 반쪽이 머리를 톡톡.

## [05:00 ~ 05:45] 열린 결말: 아침형 인간
- **대사 38번 뒤 → 39번 앞**
  "딸꾹!" 소리에 깨어나는 제로. 결혼식 피로연장 테이블, 팔에 깃털 하나가 붙어 있다. → 몇 주 뒤, 같은 카페.
- **대사 39번 뒤 → 40번 앞**
  노란 머플러의 상대가 웃으며 말한다(입 모양만): "저 아침형이에요." 반쪽이가 습관처럼 빨간 X 팻말을 반쯤 들다가 멈춘다. 다른 손의 나침반을 내려다본다. 상대가 크게 웃는 순간 반쪽이 표정이 흔들림.
- **대사 40번 뒤 → 41번 앞**
  헤어지는 길. 제로 폰에 보낼 문자 두 개가 나란히 떠 있다: [오늘 즐거웠어요. 다음에 봬요] / [다음 주 토요일 아침에, 같이 산책할래요?]
- **대사 41번 뒤 → 42번 앞**
  제로의 엄지가 두 문장 사이에서 멈춘다. 손바닥 위 반쪽이가 X 팻말과 나침반을 양손에 하나씩 든 채, 제로를 올려다보며 기다린다.
- **대사 42번 뒤 → 43번 앞**
  엄지가 내려가는 순간 — 암전. 검은 화면에 "딸꾹" 소리 한 번.
- **대사 43번 (검은 화면 자막 + 나레이션)**
