# '운명의 반쪽'을 찾느라 지치는 사람들 — 화면 연출 v1 (플라톤 『향연』 아리스토파네스)

화면 연출만. 각 묶음 위의 번호는 `대본_v1.md`의 줄 번호다. "대사 3번 뒤 → 4번 앞"은 3번 줄이 끝나고 4번 줄이 나오기 전부터 깔리는 화면이라는 뜻(다음 대사 동안 이어짐).

[영상 제목]
 * 추천: '운명의 반쪽'이라는 말을 처음 한 사람 | 플라톤 『향연』
 * A/B: 내 반쪽은 어디 있을까? 2400년 전 술자리에서 시작된 이야기
 * A/B: 딱 맞는 사람을 찾느라 지친 당신에게
[썸네일] 반으로 쪼개진 둥근 사람(팔다리 넷씩, 얼굴 둘)의 한쪽이 된 제로가 잘린 면을 내밀고 두리번. 뒤로 금 간 하늘의 제우스 번개(얼굴 없음). 글자: "내 반쪽은" / "어디에?" (철학자 얼굴 없음)
[예상 러닝타임] 약 5분 15초 (말 약 1,050자 + 말 없는 장면)
[캐릭터]
 * 제로(주황 티, 서른넷 직장인): 왼쪽 옆구리에 '잘린 면'이 있다(퍼즐 가장자리처럼 울퉁불퉁한 테두리, 2막 이후에만 보임). 사람을 만나면 그 면을 슬쩍 대 본다.
 * 반쪽 본: 제로가 지갑에 넣고 다니는 종이 본(제로 잘린 면과 똑같은 모양). 대 보면 "삐-" 하고 안 맞는 곳에 빨간 표시. 내 안의 '딱 맞아야 해'.
 * 친구(신랑) 세 명: 인트로·결말의 결혼식.
 * 아리스토파네스: 희극 작가 스틱맨. 짧은 곱슬머리, 희극 가면을 머리에 올림. 딸꾹질할 때마다 몸이 들썩.
 * 에뤽시마코스: 의사. 흰 망토, 약초 주머니.
 * 아가톤: 집주인 시인. 월계관.
 * 소크라테스: 기존 채널 소크라테스 디자인(맨발, 대머리, 수염). 4막에서만.
 * 둥근 사람들: 공 모양 몸에 팔 넷·다리 넷·얼굴 둘(앞뒤). 세 색(해=주황, 땅=초록, 달=은색).
[연출 기준] 연출 기획서 v3 + 물리 점검표. 설명보다 그림. 고대 장면은 세피아+붉은 항아리 그림 색(검은 윤곽, 테라코타 배경). 둥근 사람은 귀엽게, 성적인 묘사 없음.

## [00:00 ~ 00:40] 인트로: 올가을 세 번째 결혼식
- **첫 대사 앞**
  결혼식장. 단풍 장식. 제로 축의금 봉투 세 장을 차례로 내는 컷이 빠르게 겹친다(9월, 10월, 11월 날짜 도장).
- **대사 1번 뒤 → 2번 앞**
  신랑 친구가 신부 손을 들어 보이며 활짝. 둘 사이에 하트 퍼즐 두 조각이 '딱' 맞는 그림.
- **대사 2번 뒤 → 3번 앞**
  하객석의 제로, 박수 치다 멈칫. 혼자 손바닥을 내려다봄.
- **대사 3번 뒤 → 4번 앞**
  몽타주: 소개팅 세 번. 테이블 아래에서 제로가 지갑 속 '반쪽 본'을 꺼내 상대 쪽으로 슬쩍 대 본다. 삐- 빨간 표시(①말 빠름 ②고양이파 ③아침형). 상대는 영문도 모르고 웃는다.
- **대사 4번 뒤 → 5번 앞**
  반쪽 본에 클로즈업. 종이 끝에 작은 글씨 '운명의 반쪽'. 화면이 세피아로 물들며 시간이 되감긴다(달력이 휘리릭).
- **대사 5번 뒤 → 6번 앞**
  등불 켜진 고대 아테네의 집. 기댄 의자에 누운 손님들 사이에서 한 사람이 "딸꾹!" 몸이 들썩. 타이틀 [제로의 세계].

## [00:40 ~ 01:30] 1막: 딸꾹질하는 희극 작가
- **대사 6번 뒤 → 7번 앞**
  아가톤의 집 연회. 월계관의 아가톤, 포도주 동이, 기다란 소파에 비스듬히 누운 손님들. 자막 라벨 "기원전 416년, 아테네".
- **대사 7번 뒤 → 8번 앞**
  아리스토파네스 차례. 일어서는데 "딸꾹!" 손님들 시선 집중. 말하려다 또 "딸꾹!"
- **대사 8번 뒤 → 9번 앞**
  의사 에뤽시마코스가 손가락 셋을 펴며 처방. 1) 숨 참기(얼굴 빨개짐) 2) 물 가글(꼬르륵) 3) 깃털로 코 간지럽히기.
- **대사 9번 뒤 → 10번 앞**
  거대한 재채기. 등불이 흔들리고 아가톤 월계관이 날아감. 아리스토파네스 뿌듯.
- **대사 10번 뒤 → 11번 앞**
  두루마리 책 카드 『향연』 · 플라톤. 두루마리가 펼쳐지며 2막의 둥근 사람 그림이 살짝 보인다.

## [01:30 ~ 02:30] 2막: 반으로 쪼개진 둥근 사람
- **대사 11번 뒤 → 12번 앞**
  붉은 항아리 그림 화풍으로 전환. 공 모양 사람 하나가 화면 가운데 '뿅'. 팔 넷, 다리 넷, 앞뒤 얼굴 둘이 동시에 손을 흔듦.
- **대사 12번 뒤 → 13번 앞**
  세 색의 둥근 사람(해·땅·달)이 나란히. 그다음 팔다리 여덟으로 바퀴처럼 데굴데굴 공중제비. 들판을 가로지르는 바퀴 행렬.
- **대사 13번 뒤 → 14번 앞**
  둥근 사람들이 서로 올라타 탑을 쌓아 구름 위 올림포스로 굴러 올라감. 신들의 궁전 기둥이 흔들림.
- **대사 14번 뒤 → 15번 앞**
  번개 든 제우스(얼굴은 구름에 가려 보이지 않음)가 머리카락 한 올을 팽팽히 당겨 둥근 사람을 '스윽' 자름. 옆에 비교 그림으로 삶은 달걀이 머리카락에 잘리는 작은 컷.
- **대사 15번 뒤 → 16번 앞**
  아폴론(얼굴은 햇빛 역광)이 잘린 반쪽의 얼굴을 잘린 쪽으로 빙글 돌려 주고, 배 가운데 살가죽을 주머니 끈처럼 '쪼옥' 오므려 묶는다. 매듭 → 배꼽으로 줌인. 현대의 제로가 자기 배꼽을 내려다보는 1초 컷(웃음).
- **대사 16번 뒤 → 17번 앞**
  반쪽들이 두리번거리며 서로의 잘린 면을 찾는다. 짝을 찾은 둘이 와락 껴안는다. 들판 곳곳에서 껴안은 반쪽들.
- **대사 17번 뒤 → 18번 앞**
  아리스토파네스가 연회장에서 잔을 들고 마무리. 손님들 박수. 제로 옆구리에 '잘린 면' 테두리가 처음으로 반짝 보인다.

## [02:30 ~ 03:30] 3막: 범인은 따로 있다
- **대사 18번 뒤 → 19번 앞**
  두루마리가 다시 감기다가 멈춤. 아직 안 읽은 끝부분이 남아 있다(붉은 리본).
- **대사 19번 뒤 → 20번 앞**
  대장장이 헤파이스토스(망치, 모루, 얼굴은 화로 연기에 가림)가 껴안은 연인에게 망치를 들어 보이며 "붙여 줄까?" 연인 둘이 눈을 반짝이며 고개를 끄덕임.
- **대사 20번 뒤 → 21번 앞**
  들판의 모든 연인이 줄을 서서 손을 듦. 제로도 줄 끝에서 손을 번쩍.
- **대사 21번 뒤 → 22번 앞**
  쾅쾅 용접 불꽃 → 완벽하게 붙은 둘. 걸으려 하자 왼발·오른발이 서로 다른 쪽으로 가서 '쿵' 넘어짐. 물 마시러 가려는데 한쪽은 잠이 오고. 땀.
- **대사 22번 뒤 → 23번 앞**
  들판의 껴안은 반쪽들 위로 해가 여러 번 뜨고 지고, 하나둘 비쩍 마르며 옆으로 쓰러진다(검은 실루엣으로 짧게, 무섭지 않게).
- **대사 23번 뒤 → 24번 앞**
  현대로 돌아옴. 스포트라이트와 "범인" 딱지가 사랑의 하트를 지나쳐 제로 지갑 속 '반쪽 본'에 '착' 붙음.
- **대사 24번 뒤 → 25번 앞**
  다시 소개팅 몽타주. 이번엔 상대가 조금만 다르게 말해도 반쪽 본이 "삐-삐-삐" 요란하게 울리고, 제로가 슬그머니 계산서를 집어 든다. 상대의 아쉬운 얼굴.

## [03:30 ~ 04:35] 4막: 소크라테스의 반박
- **대사 25번 뒤 → 26번 앞**
  다시 연회장. 맨발의 소크라테스가 소파에서 몸을 일으킨다. 아리스토파네스가 "또 시작이군" 하는 표정.
- **대사 26번 뒤 → 27번 앞**
  소크라테스 말풍선 속 회상: 베일을 쓴 여인 디오티마(얼굴은 베일 그늘)가 젊은 소크라테스에게 손가락을 세워 설명.
- **대사 27번 뒤 → 28번 앞**
  상처 난 손가락에 붕대를 감는 그림 → "내 것이라도 나쁘면 버린다"는 뜻의 짧은 비유 그림(잘라 내는 장면은 그리지 않음, 가위와 붕대만).
- **대사 28번 뒤 → 29번 앞**
  두 사람이 퍼즐을 맞추는 대신, 언덕 위 같은 쪽(해 뜨는 쪽)을 함께 바라보며 걷는 그림. 둘의 그림자가 길게 나란히.
- **대사 29번 뒤 → 30번 앞**
  제로가 반쪽 본을 꺼내 들여다본다. 잘린 면의 울퉁불퉁한 테두리가 의외로 귀엽다.

## [04:35 ~ 05:15] 열린 결말: 네 번째 결혼식
- **대사 30번 뒤 → 31번 앞**
  12월, 네 번째 결혼식. 이번 신랑 신부는 퍼즐처럼 딱 맞지 않는다. 키 차이 커서 반지를 끼우다 휘청, 서로 웃음.
  신부 부케가 하객석으로 날아오고, 제로 앞에 툭 떨어짐. 옆자리 하객도 동시에 손을 뻗었다. 둘의 손이 부케 위에서 엇갈려 맞부딪힘. 딱 맞지 않는, 어색한 겹침.
- **대사 31번 뒤 → 32번 앞**
  제로가 다른 손으로 지갑 속 반쪽 본을 꺼내려다 멈춘다.
- **대사 32번 뒤 → 33번 앞**
  반쪽 본을 꺼내지 않은 채, 엇갈린 손을 그대로 두고 옆 사람을 본다. 옆 사람이 웃는다. 그 순간 — 암전. 검은 화면에 작은 공 하나가 '데굴' 굴러가는 소리.
- **대사 33번 (검은 화면 자막 + 나레이션)**
