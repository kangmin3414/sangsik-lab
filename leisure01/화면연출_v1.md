# 로봇이 내 일을 대신하는 날, 우리는 무엇으로 살까 — 화면 연출 v1

화면 연출만. 번호는 `대본_v1.md`의 줄 번호다. "N번 뒤 → M번 앞"은 N번 줄이 끝나고 M번 줄이 나오기 전부터 깔리는 화면이다.
운영자 톤(원문 `SCRIPT_asis.md`): **게임 같은 UI·판타지 효과 없이** 현실 공간 중심, 정적인 구도, 인물의 표정·손짓·물건으로 감정을 싣는다. 색은 앞쪽 차가운 파랑·회색 → 뒤로 갈수록 따뜻한 호박색·주황으로 서서히 연다. 침묵은 대본에 적힌 자리(11·32·35·37번)에 그대로 둔다.
엔진: 기본 스틱맨 + 그린 세트(`zw/gf.js`의 방·창문·언덕 같은 무대만 쓰고 게이지·도장·색종이·카드 튀어나오기는 쓰지 않는다). 손그림 떨림 끔, 가장자리 어둡게(vig)는 아주 약하게. 자막은 아래 가운데 어두운 반투명 띠(성경과 불경 편 `tbSub`와 같은 방식). 장면 코드 접두사 **ls**.

## 물리·연출 점검 메모
- 오프닝 로봇의 반복 동작은 정확히 같은 주기로(예: 2.4초), 33번 회상 컷에서도 같은 주기를 쓴다.
- 기타 케이스(5번)와 창문 속 기타(32번)는 같은 모양·색. 케이스 위 택배 상자는 32번 장면 전에 치워져 있어야 한다(창문 안 바닥에 내려놓인 상자가 살짝 보이게).
- 마리엔탈(13~15번)은 흑백·세피아로만, 현재 장면과 섞지 않는다. 아리스토텔레스 서재(17~23번)는 '상상 장면'이라 처음과 끝에 식탁 → 서재 → 식탁으로 부드럽게 바뀐다.
- 화면 글자는 내레이션을 반복하지 않는다: 13번 꼬리표, 15번 공책 낱말, 23번 칠판, 37번 인용 카드만.
- 아래 18%는 자막 자리. 공책(15번)·칠판(23번) 글자는 그 위에.
