# 죽음의 수용소에서 편 — 1막 샘플 화면 연출 (2026-11-15)

- 대본: `SCRIPT_asis.md` 그대로(운영자 "고대로 샘플 제작 가자"). 샘플은 오프닝 + 빅터 프랭클의 발견(10줄)이다.
- 한 편을 꿰는 표시: **마음 하트 게이지(5칸)**와 **가슴 속 노란 불씨**. 같은 비를 맞아도 게이지와 불씨만 달라진다.
- 프랭클 장면은 흑백 동화책 톤이다. 색은 불씨의 노랑 하나뿐이다. 폭력과 죽음은 보여 주지 않고, 잃은 것은 소지품 칸이 비는 것으로만 보여 준다.
- 기기 화면 없음, 실존 상표 없음, 채널명은 제목 카드(1.8초)에만.
