# 장면 논리 점검 (렌더 전 필수)

016에서 운영자가 "논리적이지 않은 오류가 많다"고 지적했다. 그때 찾은 오류 25가지 정도가 아래 체크리스트다. 장면을 새로 짜면 **처음부터 이 기준으로** 만들고, 렌더 전에 반드시 점검한다.

## 1. 캡처 도구
편 폴더에서:
```bash
python3 fake_tl.py                                  # 목소리 전이면 글자 수로 만든 가짜 타임라인
python3 peek.py timeline_fake.json _p.jpg           # 줄마다 65% 시점 1장(AT=0.5 처럼 바꿀 수 있음), JS 오류 출력
python3 peek3.py timeline.json _a1.jpg 0 12         # 줄마다 10%·50%·92% 세 장 + 자막 문장 — 이걸로 점검
```
- 한 시트에 10~13줄씩 끊어서 Read 도구로 **크게** 본다. 작은 시트(4열 77장)로는 오류를 놓친다.
- JS 오류(`JS ...`)가 찍히면 먼저 고친다.
- 고친 뒤에는 그 줄만 다시 peek3로 확인하고, 마지막에 전체를 한 번 더 훑는다.

## 2. 체크리스트 — 줄마다 "자막 문장 ↔ 세 장면"을 대조
**A. 시대·장소**
- [ ] 현대 인물(제로·임원·팀장)이 고대 배경(전국 시대 등)에 서 있지 않은가? 고대 장면엔 고대 인물만. 제로가 옛이야기를 듣는 장면은 연구실·화면 속 인용 카드로.
- [ ] 이야기 흐름상 같은 사건인데 장소가 순간이동하지 않는가? (016: 금요일 회의 도중 산꼭대기 → 회의실 안에서 칭찬·비난이 바람처럼 지나가게)
- [ ] 그 인물이 그 장소에 있을 이유가 있는가? (밤에 박사님이 제로 집에 → 영상통화)

**B. 순서·인과**
- [ ] 내레이션이 "~이 뜹니다/나타납니다"라고 하기 전에 그것이 이미 화면에 있지 않은가? (016: "고친 그래프가 뜹니다" 전에 고친 그래프가 보였음)
- [ ] 라벨·말풍선이 해당 단어를 말할 때 나오는가? `at16(t, a, '단어')` 처럼 문장 속 위치로 타이밍을 건다.
- [ ] 한 줄 안에서 장면이 바뀔 때(문장 둘) 전환 시점이 실제 음성 경계인가? segs가 있으면 `segLt(t, lt, 1)` 사용.

**C. 말하는 사람**
- [ ] 말풍선·라벨이 그 말을 한 인물 위에 있는가? (016: "산 같아요"는 제로의 생각인데 임원 머리 위에 있었음 → 제로 옆 생각 풍선)
- [ ] 노란 자막(인물 대사)과 화면 속 인물 입모양/위치가 맞는가?

**D. 연속성(직전 줄과 비교)**
- [ ] 직전 줄에 있던 사람·소품이 이유 없이 사라지거나 늘지 않는가? (임원 3명 → 2명, 책상이 사라짐)
- [ ] 크기(제로가 작아짐 등)·망토 상태가 이야기 진행과 맞는가?
- [ ] 같은 슬라이드·그래프가 장면마다 같은 상태인가?

**E. 물리·상식**
- [ ] 실내에서 바람이 불지 않는가? (망토가 바람을 타는 장면 → 밖으로)
- [ ] 비탈길에서 몸을 기울이지 않았는가(사람은 수직으로 선다)? 발이 지면에 닿는가?
- [ ] 탁자·책상에 다리가 있는가, 공중에 떠 있지 않은가?
- [ ] 앉은 사람은 의자/탁자 뒤에, 선 사람은 탁자 위가 아니라 바닥에. 왕은 옥좌에 **앉는다**.
- [ ] 거울에 비치려면 거울 옆·앞에 서 있어야 한다. 반사상은 같은 높이.
- [ ] 문은 경첩 쪽으로 열린다. 걷는 방향과 몸 방향이 같다(오른쪽에서 들어오면 `flip`).
- [ ] 누운 사람(침대)이 이불에 가려 안 보이지 않는가?

**F. 화면 구성**
- [ ] 오른쪽 위 HUD(요일·실험 표시)와 라벨·인용 카드가 겹치지 않는가?
- [ ] 인용 카드가 인물 머리를 가리지 않는가?
- [ ] 아래 1/5은 자막 자리 — 중요한 그림을 두지 않는다.
- [ ] 아이콘이 무엇인지 알아볼 수 있는가(돋보기가 흰 점으로 보이지 않게)?
- [ ] 화면 속 숫자·라벨이 대본 사실과 같은가? 개념도면 "개념도" 표시.

## 3. 고치는 방법
- 장면 함수를 통째로 바꿀 땐 `python3 mencius016/replfn.py <scenes파일> <새코드.js>` (같은 이름 `function` 블록을 교체, 없는 함수는 추가). `const` 줄은 옮겨지지 않으니 직접 넣는다.
- 작은 수정은 Python으로 문자열 치환하되, 바꿀 문자열이 정확히 1번 나오는지 assert 한다.
- 여러 장면이 쓰는 배경(회의실·욕실·방)은 함수로 만들어 재사용해야 장면 사이 연속성이 맞는다(016: `friday16`, `bath16`, `room16`).

## 4. 보고
고친 항목을 "줄 번호 · 무엇이 이상했나 → 어떻게 바꿨나" 형식으로, 유형별(시대·순서·말하는 사람·연속성·물리)로 묶어 운영자에게 알린다. 직접 영상을 끝까지 본 게 아니라 캡처로 확인했다면 그렇게 말한다.
