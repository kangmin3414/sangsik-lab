# 업로드 문구 · Studio · 쇼츠

## 1. 업로드 문구 파일
편 폴더에 `유튜브_업로드_실험<번호>_v1.txt`. 기준 예: `mencius016/유튜브_업로드_실험016_v1.txt`, `lonely014/유튜브_업로드_실험014_v1.txt`.
구성 순서:
1. `[제목 · A/B 테스트]` A(공감형, 따옴표 속 고민 + 철학자) / B(궁금증형)
2. `[설명란]` 고민 2~3줄 → 철학자 소개 1줄 → 제로의 실험 1줄
3. `📌 타임라인` — **최종 목소리의 timeline.json 기준**(초벌 기준이면 다시 맞춤). `srt<번호>.py`가 장면별 시작 시각을 출력한다. 실험 구간은 `[실험 n]`.
4. `💬` 댓글 질문(이름 대신 관계만) / `✍️` 오늘 해 볼 한 가지 / `🔔` 구독 링크
5. `📚 참고 연구` 저자(연도) 학술지 – 표본·결과 한 줄. 재현 실패가 있으면 같이 적는다. `📖 원전` 편·장.
6. `※` 고지: 인용 출처 구분, 도움 안내(정신건강위기상담 1577-0199, 24시간), "대본·목소리 제작에 AI 도구 활용", "제로의 이야기는 연출, 그래프는 개념도".
7. 해시태그 6~7개 → `[태그]` 15~20개 → `[고정 댓글 · 게시 전 승인]` → `[업로드 설정]`(카테고리 교육, 자막 파일, 썸네일 A/B 파일, 배경음악, 목소리, 영상 파일, 재생목록, 공개 예약).
제목 100자, 설명 5,000자 이하.

## 2. Studio 운영 규칙 (반드시)
- **'삭제'는 절대 누르지 않는다.** 옛 버전은 비공개로 바꾸고 '삭제 예정 (예전 버전)' 재생목록에 넣는다. 실제 삭제는 운영자가.
- 태그 칩은 **키보드 Backspace로만** 지운다. X(전체 삭제) 아이콘 금지.
- 댓글·커뮤니티 게시물은 운영자의 명시적 승인 후에만.
- 운영자가 브라우저를 쓰는 중엔 쓰지 않는다. 계정을 바꾸지 않는다. 업로드 중인 탭은 이동하지 않는다.
- Studio 작업은 운영자 컴퓨터의 Claude in Chrome으로만 가능(클라우드 세션에선 불가).

## 3. Studio 절차 (HANDOFF.md 7절 요약)
- 10MB 이하는 업로드 대화상자 file input에 바로. 큰 파일은 `replace/split_upload.py`로 9.4MB 조각 → 브라우저에서 Blob으로 합치고 sha256 확인. 업로드 페이지는 Trusted Types 때문에 eval 불가 → 헬퍼 코드를 직접 붙여 넣는다.
- 제목·설명은 `execCommand('insertText')`. '아동용 아님' 확인.
- 예약: 다음 ×3 → 예약 펼치기 → 날짜 `2026. MM. DD.` + Enter → 시간 항목 클릭 → 값 확인 → '예약'. **시간이 '오전 12:00'(자정)으로 기본 설정되는 함정**에 주의. 롱폼은 보통 18:00.
- 옛 버전 비공개: 편집 페이지에서 `eval(localStorage.getItem('__privsrc'))` (활성 탭에서).
- 재생목록: 제로의 실험 전체(처음부터 보기) + 🏛️ 철학자처럼 살아 보기 + 주제별(흔들리는 마음 | 관계와 외로움 | 시간과 습관).
- 엔딩 화면: 템플릿 '동영상 1개, 구독 1개'(예약 영상은 직접 고를 수 없음).
- 자막: 자막 편집 → ⋮ → 파일 업로드 → 타이밍 포함 → srt → 게시.
- A/B 썸네일: 'A/B 테스팅' → '썸네일만' → 2·3번 칸 업로드 → 저장.
- 업로드한 영상 ID와 메타데이터는 `replace/lf_repl.json`, 쇼츠는 `replace/shorts_repl*.json`에 기록하고 HANDOFF.md 롱폼 표를 갱신한다.

## 4. 썸네일
- 편의 장면 코드로 만든다(`mencius016/thumb016.py`가 예): 같은 캐릭터·색, 큰 한국어 두 줄(흰 + 노랑 강조), 대비되는 두 인물(작아진 제로 vs 큰 상대 등).
- 글자가 인물 얼굴을 가리지 않게, 모바일에서 읽히게(줄당 6~8자).
- A/B는 공감형(U) / 궁금증형(T) 두 개 이상.

## 5. 쇼츠
- 잘된 쇼츠는 조회의 약 95%가 쇼츠 피드에서 온다 → **썸네일보다 첫 1~2초 훅**. 0프레임이 검은 화면이면 안 된다.
- 결론(가장 강한 한 줄)을 앞으로, 1.15배속, 엔딩 카드 없이(006 스토아 리컷 방식, `replace/build_remix006.py`).
- 제작: `replace/build_newN.py` + `plan_newN.json`을 복사해 씀. 아웃트로 음성은 `replace/outro_keep`. 파일명 `쇼츠_<편>[vN]-<번호>_<이름>.mp4`.
- 설명: 2~3줄 요약 → "📌 … 전체 실험은 채널에서!" → 💬 질문 → 📚 출처 → "※ 제로의 이야기는 연출" → 해시태그(#shorts 포함).
- 하루 1~2개, 이미 예약된 쇼츠와 날짜가 겹치지 않게. 롱폼 공개 뒤로 예약하고, 공개되면 관련 동영상으로 롱폼을 연결.
