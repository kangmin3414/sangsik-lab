# 상식실험실 대본 작성·사실 확인

채널: 상식실험실. 주인공 스틱맨 '제로', 해설 '박사님'(할아버지 과학자). 편마다 철학자 소품을 붙였다 뗀다.
형식: "만약에 ○○처럼 산다면?" — 현대인의 고민 → 철학자 → 하루 하나씩 실험(보통 3~5개) → 마무리.
항상 한국어로 답한다.

## 0. 시작 전에
1. 겹침 확인: 새 주제의 핵심어(철학자, 연구자, 개념, 일화)를 기존 대본에서 grep 한다.
   `grep -l "<핵심어>" */script.py` — 겹치면 빼거나 각도를 바꾼다. (예: 015는 014와 겹치던 헤겔 일화·푸들·고독 인용·혼자 15분을 뺐다.)
2. 최신 편 대본 하나(예: `mencius016/script.py`, `lonely014/script.py`)를 읽고 문체를 맞춘다.

## 1. 구성 규칙
- **20초 안에 핵심 질문과 실험 예고.** 롱폼 시청 지속률이 50% 미만이라 생긴 규칙. 0~20초에 장면 한 줄 + 질문 + "오늘의 실험" 약속까지. "~한 경험 있으시죠?"로 길게 여는 도입 금지.
- **비유 하나로 끝까지.** 예: 014 고슴도치 거리, 016 작아지는 몸과 망토(기운). 대본 머리 주석 `# One image all the way:`에 적는다.
- **실험은 실패도 있어야 실험이다.** 다섯 개 모두 "신기하게도 사라졌습니다"로 끝나면 교훈집이 된다. 중간(3일 차 등)에 진짜 실패·반전을 넣고, 마지막에 앞의 장치를 회수한다(016: 숨겨 둔 틀린 숫자 → 고친 그래프 → "숨길 게 없으니까").
- 제로·박사·조연은 짧은 대사(segs)로 끼워 넣고, 내레이션 문장은 짧게(한 문장 한 호흡).
- 마무리: 한 줄 정리 → 오늘 해 볼 한 가지 → 댓글 질문(이름 대신 관계만) → 필요하면 도움 안내(정신건강위기상담 1577-0199) → "상식실험실이었습니다."
- 위로 문장에는 균형 한 줄: "힘든 시간이 그 자체로 좋은 건 아닙니다" 류.
- 니체(005) 편은 줄이지 않는다.

## 2. 분량
- 목표 롱폼 8:20~8:40 ≈ 자막 글자 수 **2,850~2,950자** (Gemini TTS 기준 약 5.6자/초; 014는 2,872자 → 8:31, 016은 2,930자 → 8:25).
- 계산: `python3 -c "from script import S; print(sum(len(x[2]) for x in S))"` (편 폴더에서).
- 초벌 로컬 TTS(supertonic)는 더 빠르다(2,930자 → 7:05). 분량 판단은 Gemini 기준으로.

## 2-1. 템포 (2026-10-31 운영자 요청: 루즈하지 않게, 인위적 배속 없이)
- **글로 빠르게**: 한 문장 한 정보, 20자 안팎. 접속사·설명 꼬리("~라는 것입니다", "~했던 거죠") 줄이기. 숫자는 문장 맨 앞에.
- **질문으로 끌기**: 단계·장 끝 문장 = 다음 장면을 여는 질문/연결("그런데 1등이 되자…").
- **목소리 스타일**: style38.json `base`를 이야기꾼 톤으로 — 같은 Schedar, "친구에게 실화를 들려주듯 한 호흡, 쉼은 아주 짧게, 쉼표에서 멈추지 말고". 측정: 같은 문장 5.9 → 6.8자/초(+15%), 문장을 줄이면 같은 내용이 40% 짧아짐(leekunhee019/tempo).
- **쉼 줄이기**: tts38seg.py 줄 사이 0.5→0.3초, 장면 바뀔 때 +0.2→+0.15, `cap_pause` [0.45, 0.3]. `pause`는 장 전환 1~2곳만.
- **화면**: 그림·장면은 4~6초마다 바뀌게(한 줄이 길면 그림 둘로).
- 분량 기준이 바뀜: 이 템포면 2,950자 ≈ 7분 30초. 8분대를 원하면 3,300~3,400자.

## 3. 사실 확인 (가장 중요)
운영자 초안에는 그럴듯한 오류가 자주 섞여 온다. 016 초안에서 실제로 나온 것들:
- **재현 실패한 연구를 사실처럼**: 파워 포즈 "테스토스테론 +20%, 코르티솔 −25%"(Carney 2010) → Ranehill 2015(200명) 재현 실패, 제1저자 Carney 2016 철회. 쓰려면 "더 큰 실험에서 확인되지 않았다"고 밝히고, 남은 효과만 말한다.
- **인용의 주인 착각**: "부유함엔 어짊으로…"는 맹자가 인용한 증자의 말. "스스로 돌아보아 곧다면…"은 공자→증자로 전해진 말.
- **지어낸 문장을 원문처럼**: 원문 뒤에 그럴듯한 해석을 붙여 한 인용처럼 만든 것. 원문과 해석을 "맹자의 말은 이런 뜻이었습니다"로 분리.
- **오역**: 勞其筋骨 = 몸을 수고롭게(❌ 뼈마디를 꺾으며).
- **없는 용어**: '부지위', '탈맥락화' 같은 말 → 실제 개념(후광 효과 Thorndike 1920 등)으로 바꾼다.
- **맥락 착각**: 공손추의 질문은 "어떤 경지냐"가 아니라 "재상이 되시면 마음이 흔들리시겠습니까".
- **흔한 오귀속**: "우리는 반복하는 것이 된다"는 아리스토텔레스가 아니라 Will Durant의 요약. 칸트 산책·시계 이야기는 일화로 밝힌다.

확인 절차:
1. 철학 인용은 원문(한문·독일어·그리스어 등)과 출처(편·장)를 찾아 대본 머리 주석 `# Facts (checked 날짜):`에 적는다.
2. 연구는 저자·연도·학술지·표본 수·핵심 결과를 확인하고, **재현 연구·메타분석·철회 여부**를 따로 검색한다.
3. 숫자는 원문 그대로. 반올림·과장 금지("명확한 숫자로 증명" 같은 표현 금지).
4. 개념도(그래프가 실제 수치가 아닐 때)는 장면에 "개념도"라고 표시하도록 메모.
5. 허구(제로의 일주일, 등장인물)는 주석에 "fiction"으로 적고, 업로드 설명에 "연출" 고지.

## 4. script.py 형식
```python
# 실험 0NN · 제목 — 철학자 (대본 1차, 날짜)
# (scene, args, subtitle, spoken-or-None). args["segs"] = [(voice, text[, spoken])...] when a line mixes voices.
# Voices: N narrator, Z Zero, D doctor, ... 
# One image all the way: ...
# Story: ...
# Facts (checked ...): ...
S = [
 ("hlift", {}, "자막 문장.", None),
 ("hlift", {"k": 1, "segs": [("Z", "제로 대사.")]}, "제로 대사.", None),
 ("hposes", {"study": "Nair 외 (2015)"}, "74명의 …", "칠십사 명의 …"),   # 4번째 = TTS용 발음(숫자는 한글로)
 ("hfix", {"k": 3, "pause": 0.4}, "그날 저녁, …", None),
]
```
- scene 이름은 편 접두어 + 짧은 영문(016은 h…, 014는 l…). 같은 scene의 여러 줄은 `k`로 구분.
- segs를 쓰면 subtitle은 segs 텍스트를 공백으로 이은 것과 **정확히 같아야** 한다(검사: `' '.join(t[1] for t in segs) == subtitle`).
- 숫자·연도·영문은 spoken(4번째 칸)에 한글 발음을 준다. 발음이 틀리기 쉬운 말(예: "어짊으로" → "어진 마음으로")은 자막까지 같이 바꾸는 편이 낫다.
- 연구 줄에는 `{"study": "저자 (연도)"}` 를 달아 화면 왼쪽 위 태그로 나오게 한다.
- `script_read.md`(읽기용)를 함께 만든다: 섹션 제목 + 화자 표시.

## 5. 평가를 요청받았을 때
표로 점수(주제·구성·사실 정확도·대사·연출 지시)와 함께, "꼭 고칠 것"(사실 오류·채널 규칙 위반)과 "더 좋게"를 나눠 준다. 고칠 문장은 원문과 수정안을 나란히.
