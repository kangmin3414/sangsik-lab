v2 → v3 (운영자 요청: 실험 설명을 줄이고 그림으로 보여 주기, 수능 보는 학생에게 열린 결말로 감동, 이해하기 쉽게)
 * **실험 설명 전부 뺌**(운전면허·미식축구·정년 심사). 내레이션의 개념은 '영향력 편향' 한 문장뿐. 연구는 설명란 원전에만 적는다.
 * 연구 내용은 그림 장치로만 보여 준다.
   - 예언이의 구슬이 시험지 한 장만 비춘다 → 초점 착각
   - 영수증에 '다음 주 화요일'을 적을수록 구슬이 넓어진다 → 미식축구 연구의 '하루 적기' 과제
   - 제로의 16년 몽타주에서 반창고 일꾼이 하트를 붙인다 → 마음의 면역계
   - 어른들 머리 위에서 잠든 예언이 → "어른들도 그랬지만 지금은 이렇게 됐다"
 * 시점을 **수능 전날 밤**으로 옮김. 공개(11/15~17)가 시험 전이라, 시청자인 수험생이 지금 겪는 밤과 같게. v2의 "가채점 했는데 끝났어요"는 뺐다.
 * **열린 결말**: 수능 날 아침 교문 → 1교시 뒤 다시 깨어난 예언이와 점심 도시락·영수증 → 오후 1시 10분 멈춘 비행기 → 해 질 녘 시험장을 나서는 서윤의 뒷모습. 결과는 보여 주지 않는다. 서윤이 영수증의 '다음 주 화요일'을 꺼내 보는 데서 끝나고, 마지막 질문은 시청자에게.
 * 세네카 인용은 영상에서 빼고 설명란으로. 수능 전날 밤이라 컵라면 대신 서윤에겐 온장고의 따뜻한 두유, 제로만 컵라면.
