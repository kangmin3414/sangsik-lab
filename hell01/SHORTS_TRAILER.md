# 지옥 불교편 · 예고편 쇼츠 기획 v2 (약 42초, 2026-11-02)

본편: `SCRIPT_v1.md` 「착하게 살면 뭐 해, 아무도 모르는데」.

**v2 (운영자: "모두 다 자연스럽게, 그리고 긴박감 있게 흘러가야 한다"):** v1은 해설이 끼어들고 날짜 카드에서 장면이 끊겨 흐름이 멈췄다. v2는 이렇게 바꾼다.

1. **해설 없음.** 모든 정보는 장면 안의 대사로만. 49재 설명도 저승사자가 걸으며 한다("49재, 들어 보셨죠? 그게 이 일정입니다").
2. **멈추지 않는 걸음.** 저승사자가 제로를 끌고 문에서 문으로 계속 걸어간다. 판결이 걸음 위에서 겹쳐 나오고, 제로의 변명은 다음 문이 열리는 소리에 잘린다. 날짜는 별도 카드 대신 화면 구석 두루마리에 도장으로 찍힌다.
3. **빨라지는 북소리.** 심장 박동 같은 북이 점점 빨라지다가, "괜찮아요 41,200번"에서 처음으로 모든 게 멈춘다. 걸음도, 북도.
4. **한 번의 정적 → 마지막 문.** 정적 뒤 저승사자가 낮게 "마지막 분입니다." 거울이 빛나는 순간 화면이 하얗게 덮이고 끊긴다.
5. **반복 재생.** 마지막 버스 브레이크 소리가 첫 장면 버스로 이어진다.
