# 미루기·완벽주의 편 v2 (밈·츤데레 힐링형) — 연출 기획
내레이션은 `SCRIPT_v2_asis.md` 원문 그대로. 화면 연출 칸에 적힌 짧은 대사(뇌 캐릭터의 "야! 섣불리…", 제로의 비명)만 캐릭터 목소리로 따로 넣는다.

## 전체 설계: 웃음 → 정적 → 따뜻함 → 다시 웃음 → 쉼
| 구간 | 톤 | 화면 리듬 | 음악 |
|---|---|---|---|
| 0:00~3:50 | 능청 밈, 거울치료 | 2~4초마다 컷, 줌 펀치, 정지 화면 + 짤 자막 | 통통 튀는 피치카토·신스 |
| 3:50~5:00 | 장난기 0, 진심 | 효과·짤 자막 전부 멈춤, 카메라 천천히 | 로파이 재즈 피아노(대본 지시) |
| 5:00~6:00 | 유쾌한 처방 | 다시 빠른 컷, 체크리스트 | 밝은 업템포 |
| 6:00~6:40 | 쉼표 | 불 끄고 달빛, 정지에 가깝게 | 피아노만 남기고 잦아듦 |

가장 중요한 연출은 **3:50의 "브레이크"**다. 직전까지 시끄럽던 효과음과 자막이 한 번에 꺼지고 1초 무음이 흐른 뒤 피아노가 들어온다. 웃다가 갑자기 조용해져야 "근데 좀 짠하지 않나요?"가 꽂힌다.

## 반복 장치
- **스탯 창 UI**: 1:15에 머리 위에 뜬 게임 창(100점 갓생러 / 0점 폐인, 중간 점수는 🔒)이 5:00 처방에서 다시 나와 잠겨 있던 '1점·7점·10점' 버튼이 하나씩 풀린다.
- **비싼 러닝화**: 인트로에서 결제 → 5:00에 결국 신는 건 삼선 슬리퍼.
- **폰**: 인트로에서 코에 떨어지던 폰이, 아웃트로에서는 손에 없다.

## 제작 방식
- 스틱맨 애니메이션 + **AI 그림 4장**: ①인트로 난장판 방(널브러진 택배 상자, 폼롤러, 러닝화, 비닐만 뜯은 태블릿, 감자처럼 누운 제로) ②두개골 투시(뽁뽁이 감긴 유리 멘탈 + 안경 쓴 뇌 캐릭터) ③3:50 따뜻한 조명 속 손바닥을 내려다보는 제로 ④아웃트로 달빛 비치는 방, 대자로 누운 제로.
- 실제 브랜드는 말로만. 화면에는 로고 없는 상자·신발·앱 화면.
- 목소리: 내레이터(능청스러운 남자 목소리, 3:50부터 같은 목소리로 차분하게 톤 전환), 뇌 캐릭터(높고 호들갑스러운 목소리). 제작 전에 내레이터 후보 3개로 첫 문단을 들어 보고 고른다.
- 효과음은 직접 합성(띠용·쿵·뽕·결제 띵·팡파레·슬로 타자). 유명 밈 효과음 원본은 쓰지 않는다(저작권).

## 구간별 연출

### 0:00~1:15 인트로 · 쿠팡 박스와 누워 있는 감자
- 첫 컷 **AI ①**. 폰을 얼굴 위에 들고 쇼츠를 넘기던 제로 코에 폰이 "쿵" → 제로 "악!"(짧은 캐릭터 소리). 화면 구석 [제로의 세계] 타이틀(채널명 결정에 따름).
- "침대에 누워서 목에 투턱 잡힌 채로 보고 계시죠?" → 카메라가 시청자 시점으로 바뀌어 제로가 화면을 빤히 본다. 턱에 주름 두 줄이 "뽁" 생기는 개그.
- "심장에 뽕이 차오르면서" → 가슴에 펌프질, 머리 위에 '갓생 호소인 모드 ON' 토글.
- 속마음 "진짜 이따위로…" → 제로가 벌떡 일어나 주먹 불끈, 배경에 불꽃.
- "자본주의 플렉스" → 카드 긁는 소리와 '결제 완료' 띵 ×3(러닝화, 템플릿 화면, 형광펜 세트가 차례로 떨어짐).
- "새벽 3시까지 스크랩" → 시계 3:00, 눈이 빨개진 제로.
- "국가대표 출정식 수준" → 단상 위 제로, 꽃가루·팡파레.
- 첫째 날 '오운완' 스티커 / 둘째 날 이 악문 얼굴, 땀 / "운명의 셋째 날" → 화면 어두워지고 드럼롤.
- **"저녁 8시 14분"** → 디지털 시계 초근접 줌 + 둥 효과음, 정지 화면.
- "정각병 도파민 회로" → 뇌 회로에 전구가 줄줄이 켜지며 "9:00"을 향해 화살표.
- 쇼츠 3개 → 손가락 스와이프 3번만에 시계가 11:40으로 빨리감기.
- 야식 주문 → 배달 앱 화면(로고 없음), 머리 쥐어뜯기.
- 자책 대사 → 단어 스티커가 머리에 하나씩 붙음: '작심삼일', '개복치'(기절하는 개복치 아이콘), '헬스장 기부천사'(돈 날개 단 천사).
- "뼈 그만 맞으시고 순살 되기 전에 스톱" → 뼈다귀 아이콘에 맞던 제로가 순살 치킨으로 변하기 직전, 거대한 STOP 표지판.
- "'완벽주의'라는 몹쓸 사기극에 낚인 것" → 낚싯바늘('완벽주의')에 걸린 제로가 위로 끌려 올라감.

### 1:15~2:30 전반부 · 중간이 없는 K-뇌
- 방이 레트로 게임 화면으로 전환(픽셀 테두리, 8비트 효과음). 머리 위 스탯 창: **[100점: 서울대 수석 갓생러] VS [0점: 방구석 폐인]**, 가운데 30·50점 버튼은 자물쇠.
- "진짜 게으른 사람은 애초에 장비도 안 사고" → 해먹에서 행복하게 자는 '진짜 게으른 NPC'(나무늘보) 등장.
- "당신의 진짜 정체는" → 제로 얼굴에 정체 공개 스포트라이트, 이름표 '지독한 완벽주의자'.
- 흑백논리 4줄 → 줄마다 짧은 상황 컷 + 점수 도장 "쾅": 헬스장 쇠질 100 / 집 팔굽혀펴기 10개 0(쓰레기) / 카페 4시간 영어 100 / 침대 단어 3개 0.
- "20점, 50점, 70점이 아예 없는" → 점수판에서 중간 숫자들이 깨져 떨어짐.
- "침대로 몸을 던져" → 슬로모션 다이빙.
- "장렬한 파업" → 이불 속에서 '파업' 머리띠, 작은 피켓.

### 2:30~3:50 중반부 1 · 멘탈 개복치
- **AI ②** 두개골 투시: 뽁뽁이에 칭칭 감긴 유리 멘탈, 옆에서 안경 쓴 뇌 캐릭터가 경보기를 흔들며 "야! 섣불리 시작했다가 망하면 우리 멍청한 거 들통나! 일단 누워 있어!"(뇌 캐릭터 목소리 + 말풍선).
- "멘탈 개복치" → 손가락으로 톡 건드리자 기절하는 개복치.
- "내 밑천이 드러나는 것" → 커튼이 걷히자 동전 몇 개 든 작은 지갑.
- "뼈가 부러지는 것만큼 아프거든요" → 엑스레이 뼈에 금 가는 컷.
- **"시작을 안 하면, 적어도 실패할 일도 없다!"** → 검은 화면에 큰 글씨 한 줄.
- 핑계 두 장면: 시험지 받고 어깨 으쓱하는 제로 + 말풍선 / 거울 앞 뱃살 + '바디프로필' 상상 구름.
- "방탄조끼" → '완벽한 준비' 라벨 방탄조끼를 입은 제로에게 날아온 '실패' 화살이 튕겨 나감.
- "이불 속으로 숨어버린" → 이불 김밥이 되어 데굴데굴.

### 3:50~5:00 중반부 2 · 반전의 위로
- 이불 김밥 정지 → 모든 효과음·자막 꺼짐, 1초 무음 → 로파이 재즈 피아노.
- **AI ③**: 어두운 방, 따뜻한 조명이 뒤통수를 감싸고 제로가 말없이 손바닥을 내려다본다.
- "정답 아니면 오답, 1등 아니면 루저" → 세피아 회상: 빨간 동그라미와 빗금이 그어진 어린 제로의 시험지, 시상대 아래 작은 제로.
- "출근길 지옥철" → 꽉 찬 회색 사람들 사이에 낀 제로, 흔들림.
- "남들은 다 재테크다 운동이다" → 휴대폰 속 남들의 반짝이는 카드들이 둥둥, 제로만 회색.
- "지친 몸을 이끌고 장비를 사고" → 인트로의 결제 장면을 이번엔 느리고 조용하게, 피곤한 얼굴로 다시 보여 준다(같은 장면, 다른 감정).
- "누구보다 잘 살고 싶어서" → 제로가 다이어리를 꼭 끌어안고, 화면이 금빛으로 번진다.
- "'쓰레기'니 '작심삼일'이니 욕하지 마세요" → 인트로에서 머리에 붙었던 단어 스티커들이 하나씩 떨어져 날아간다(인트로 회수).

### 5:00~6:00 후반부 · 처방전 "일단 개판으로 해라"
- 무릎 탁 털고 일어나는 제로, 음악이 밝게 전환.
- 러닝화를 지나쳐 삼선 슬리퍼를 직직 끌고 현관으로 → 아파트 복도 끝까지 10초 우다다(속도선, 발소리) → 벽 짚고 씩 웃으며 V.
- 큰 자막 **[대충의 미학: 일단 개판으로 해라]**.
- 처방 3개는 체크리스트로: 잠옷 스쿼트 "하나, 둘, 셋, 끝!" 후 바로 눕기 / 화장실에서 책 한 장(뚜껑 닫힌 변기에 앉은 상반신만) / 댓글 속 슬랭 하나 보고 피식.
- "에게?" → 시청자 쪽 말풍선이 삐죽 튀어나옴. "바뀝니다." 단호한 컷.
- "0점과 압도적인 1점" → 거대한 금빛 '1'이 '0' 위로 쿵 떨어지고 화면 전체가 뒤집히는 연출.
- 스탯 창 재등장: 잠겨 있던 '1점·7점·10점' 버튼의 자물쇠가 차례로 풀림(전반부 회수).
- "망작을 만들 권리" → 삐뚤빼뚤한 그림을 액자에 넣고 뿌듯한 제로, 액자 이름표 '망작'.
- "빗장이 풀리고 … 굴러가기 시작" → 자물쇠가 풀리고 바퀴가 굴러간다.

### 6:00~6:40 아웃트로 · 쉼표
- **AI ④**: 불 끈 방, 창밖 달빛, 대자로 편히 누운 제로. 손에 폰이 없다(인트로 회수).
- 채널 로고와 자막 **[구독: 내 결함과 덜 삐걱대며 사는 법]**(채널명 결정에 따름).
- "갓생 다이어리 덮으시고" → 책상 위 다이어리가 스르륵 덮힌다.
- "욕봤습니다" → 화면이 천천히 암전.

## 썸네일·제목 (궁금증 + 극단성, 첫 30초와 같은 내용)
- 썸네일: AI ①처럼 택배 상자와 새 러닝화 사이에 감자처럼 누운 제로, 얼굴 위 폰. 글자 "게을러서 / 아님". 0~30초에 나오는 장면 그대로다.
- 제목 후보: "장비 다 사고 3일 만에 눕는 사람들의 진짜 정체" — 답(완벽주의)은 1:10, 개복치는 2:30에 나온다. 운영자 A안("…'개복치'라서 그렇습니다")은 답을 제목에서 먼저 말해 버려서 궁금증이 약하다.

## 남은 결정
- 영상 안 채널명·구독 안내·끝인사(HANDOFF 규칙 충돌).
- 표현 수위("쓰레기", "개판", "말아먹는")를 그대로 갈지.
- "삼다수 삼선 슬리퍼"가 의도한 말장난인지.
