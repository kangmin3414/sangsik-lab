# 미루기·완벽주의 편 — 연출 기획 (내레이션은 SCRIPT_asis.md 원문 그대로)

## 전체 콘셉트
- **한 줄:** 니체 편이 "깨부수는" 영상이었다면, 이 편은 "풀어 주는" 영상. 터지는 효과 대신 천천히 밝아지는 빛과 숨 고르는 쉼으로 간다.
- **이어지는 장치 3개** (한 번 나오고 끝나지 않고 다시 돌아온다)
  1. **0→100 벼랑 계단**: 2막에 등장 → 4막에 그 계단이 "100점의 감옥" 창살로 바뀌었다가 문이 열린다.
  2. **유리구슬 '자존감'**: 3막에 가시덤불로 감싼다 → 4막에 손을 펴자 구슬이 따뜻하게 빛난다.
  3. **새 운동화(가격표 그대로)**: 1막 방구석 → 4막에서 신는 건 운동화가 아니라 슬리퍼. "완벽한 준비"를 포기하는 순간.
- **색:** 새벽 1시 남색 → 2막 차가운 회색 하늘 → 3막 짙은 보라·초록 가시 → 4막 아침 햇살 금색 → 5막 스탠드 주황.
- **소리:** 1~3막 낮은 피아노·패드(단조), 4막에서 대본대로 어쿠스틱 피아노(장조)로 바뀜, 5막 셀레스타 자장가풍. 모든 곡은 음성 인식으로 노래 목소리 검사.
- **속도:** 팝업·폭발 효과 최소, 카메라는 느리게 밀기. "아닙니다." 뒤 1초 정적처럼 쉼을 일부러 둔다.
- **자막:** 내레이션은 흰색, 속마음 대사("난 왜 이렇게…", 검열관 속삭임, "시작하지 않으면…")는 손글씨체(나눔펜) 회색으로 구분.

## 제작 방식
- 스틱맨 애니메이션 + **AI 그림 5장**(분위기를 정하는 큰 장면만): ①새벽 1시 방 ②구름까지 솟은 0→100 벼랑 계단 ③가시덤불 속 유리구슬 ④아침 햇살 문가 + 들꽃 ⑤스탠드 아래 찻잔과 밤하늘.
- 목소리: 내레이터 1명(차분한 중저음, 느린 속도). 속마음 줄은 같은 내레이터가 낮게 속삭이는 스타일로 따로 녹음.

## 구간별 연출

### 0:00~1:10 인트로 · 불 꺼진 방
- **AI ①**: 새벽 1시 방, 스탠드 불빛. 책상 위 두꺼운 다이어리, 먼지 앉은 자격증 책, 방구석 가격표 달린 새 운동화. 침대에서 무릎을 안은 제로.
- 폰을 껐다 켤 때마다 제로 얼굴에 빛이 깜빡이고, "푹" 한숨에 어깨가 내려앉는다. 하단에 [제로의 세계] 타이틀(채널명 결정에 따름).
- "운동복도 사고, 새 노트도 펼치고" → 세피아톤 폴라로이드 회상 두 장(운동화 사는 제로, 첫 장에 "매일 운동!" 적는 제로).
- "며칠 못 가 멈춰 서 있는" → 달력: ✓✓✓ 뒤로 빈칸이 이어진다.
- 속마음 두 줄 → 손글씨 자막, 제로 머리 위 먹구름.
- "의욕은 자책이라는 차가운 물에 꺼져버리고" → 제로 머리 위 작은 촛불('의욕')에 '자책' 양동이 물이 쏟아지고 "치익" 김.
- "게을러서 멈춘 걸까요? / 아닙니다." → 화면 정지, 1초 무음.
- "너무 잘 해내고 싶었던 마음이 커서 잠시 얼어붙은" → 제로 몸에 성에가 번지며 얼음처럼 굳는다(아프지 않게, 반짝이는 서리).

### 1:10~2:30 전반부 · 100점의 감옥
- **AI ②**: 바닥 '0'에서 구름 위 '100'까지 중간 없이 솟은 벼랑 계단, 아래 아주 작은 제로가 올려다보다 뒷걸음질.
- "두 가지 선택지밖에" → 화면이 반으로: 금빛 '100점' 문 / 잿빛 '0점' 문. 그 사이엔 아무것도 없다.
- 운동·공부 예시 → 체크리스트 카드("주 5일 · 1시간", "3~4시간 집중")가 산처럼 쌓인다.
- "야근에 치여 파김치가 된 날" → 퇴근하는 제로가 파처럼 축 늘어지는 개그 한 컷.
- "마음속 검열관" → 제로 어깨 위에 검은 법복·의사봉의 작은 검열관이 나타나 귓속말(손글씨 자막). 의사봉 "땅".
- "아예 시작조차 하지 않는 쪽을" → 현관 앞까지 갔던 제로가 침대로 되돌아간다.
- "기준이 숨이 막힐 만큼 무거웠기" → 거대한 '100' 숫자 덩어리를 짊어진 제로가 무릎을 꿇는다.

### 2:30~3:50 중반부 · 나를 지키려 얼어붙은 마음
- **AI ③**: 두 손에 든 투명한 유리구슬('자존감') 주위로 겹겹이 자라는 가시덤불 벽, 보랏빛.
- "온 힘을 다해 부딪혔는데 결과가 기대에 못 미치면" → 상상 장면: 전력 질주한 제로 앞에 '62점' 카드, 구슬에 실금이 "찡".
- "무의식적인 브레이크" → 제로 발밑 브레이크 페달, "끼익".
- **"시작하지 않으면, 실패해서 상처받을 일도 없어."** → 검은 화면에 손글씨 한 줄만.
- "장비를 사고, 계획표를 다듬으며" → 몽타주: 쇼핑백, 형광펜 다섯 색 계획표, 정리된 책상. 제로는 바쁜데 방 밖으로는 한 발도 안 나간다. "안도감"에 담요를 덮는다.
- "웅크리고 있던 내면의 조심스러운 호소" → 가시덤불 안쪽에 어린 제로가 웅크린 모습, 화면이 살짝 따뜻해진다.

### 3:50~5:10 후반부 · 불완전해도 괜찮다
- 음악이 어쿠스틱 피아노로 바뀌는 순간 창문이 열린다.
- **AI ④**: 아침 햇살이 쏟아지는 현관, 편한 옷에 슬리퍼 차림의 제로가 문을 살며시 연다. 이어서 보도블록 틈에 핀 삐뚤빼뚤한 들꽃을 내려다보며 미소.
- "선 하나에서 시작되고" → 연필선 하나가 스스로 그려지며 그림이 된다.
- "나무도 비바람에 흔들리고" → 묘목이 흔들리며 자라 큰 나무로.
- "완성된 조각상이 아니라" → 돌덩이를 정으로 조금씩 다듬는 제로.
- "'100점의 감옥' 문을 열어주세요" → 2막 계단이 창살로 변했다가 문이 열린다. 구슬을 쥔 손을 펴자 구슬이 따뜻하게 빛난다(3막 회수).
- "50점이어도, 10점이어도" → 점수판이 내려가는데 제로는 웃는다.
- "5분간 걷다 들어온 발걸음" → 가로등 밤길, 화면 구석 타이머 5:00.
- "생명의 5점" → 금빛 '+5' 배지가 제로 가슴에 스며든다.
- "책 한 쪽", "엉망인 글씨 한 줄" → 짧은 컷 두 개.
- "어설픈 한 걸음" → 슬리퍼가 문턱을 넘는 순간 슬로모션, 작은 반짝임. 방구석 새 운동화는 그대로 둔다(1막 회수).

### 5:10~6:20 아웃트로 · 쉼표
- **AI ⑤**: 스탠드 불빛 아래 김 오르는 찻잔을 든 제로, 창밖 고요한 밤하늘.
- "무거운 채찍을 내려놓으세요" → '자책'이라 적힌 채찍을 바닥에 내려놓는다.
- "살아낸 것만으로도 이미 충분히" → 1막 달력 빈칸 위에 작은 하트 스티커가 하나씩.
- 채널 로고·구독 자막 → 대본 지시대로 손글씨 로고(채널명 규칙 결정에 따름).
- "푹 주무세요" → 스탠드가 "딸깍" 꺼지고 별빛만 남은 채 천천히 암전.

## 썸네일·제목 (궁금증 + 극단성, 30초 안에 같은 내용)
- 썸네일: AI ①과 같은 방에서 무릎을 안은 제로 + 가격표 달린 새 운동화. 글자 "게을러서 / 아니었다". 첫 30초 안의 방·운동화·"난 왜 이렇게 끈기가 없을까"와 맞는다.
- 제목 후보: "자꾸 미루는 사람들의 진짜 공통점, 게으름이 아니었다" / "시작을 미루는 사람이 사실 가장 잘하고 싶은 사람인 이유". 답은 0:54("너무 잘 해내고 싶었던 마음")와 1:10("전부 아니면 전무")에 나온다.
