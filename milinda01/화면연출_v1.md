# 불교 편(수레 문답 · 무아) — 화면 연출 v1

대본 `대본_v1.md`와 같은 줄 번호. 1~32번은 1막 샘플이라 자세히, 33번부터는 전체를 만들 때 다시 다듬는다.
엔진: 게임 감각 층(`zw/gf.js`) + **몰입 층(`zw/gfx.js`, 이 편에서 새로 만듦)**. 장면 코드는 `long/mlgf.js`(접두사 ml).

## 0. 전체 약속
- **한 편을 꿰는 표시:** 화면 오른쪽 위의 작은 수레(= '나'). 부품 칸 다섯(몸·기분·기억·버릇·생각). 31번에서 처음 생기고, 뒤에서는 부품이 바뀌어도 굴러간다. 끝에서 화면을 가로질러 굴러간다.
- **딱지(속 캐릭터):** 민트색 라벨 프린터 요정. 손바닥만 하고 제로의 머리 위에 산다(어깨에 두면 얼굴을 가려서 머리 위로 옮김). 말을 하면 입(인쇄구)에서 스티커가 '찌익' 나온다. 스티커는 크림색 바탕 + 굵은 테두리 + 왼쪽 빨간 띠, 글자는 "원래 ○○". 입에서 뽑은 스티커를 던져서 붙인다: '찌익' → 휙 → '탁'(멈칫 + 충격 프레임 + 카메라 흔들림).
- **빛(몰입 층):** 장면마다 주광 하나를 정하고 인물·소품에 방향 있는 빛과 테두리 빛, 벽 그림자를 준다.
  - 일요일 밤: 주광 = 폰 화면(차가운 흰빛, 아래에서), 테두리 = 창의 달빛. 색 보정 night.
  - 월요일 회의실: 주광 = 블라인드 사이 아침 햇빛(왼쪽 위, 따뜻함), 벽에 빛줄기 무늬. 색 보정 cool 약하게.
  - 사갈라: 주광 = 늦은 오후 해(오른쪽 위, 금빛), 나뭇잎 사이 빛줄기 + 떠다니는 먼지, 테두리 빛 금색. 색 보정 gold.
- **카메라:** 모든 샷에 아주 작은 떠다님(gfxDrift). 배경·가운데·앞 세 층이 다르게 움직인다. 클로즈업에서는 배경을 흐린다. 스티커가 붙는 순간과 부품이 맞는 순간에 짧은 흔들림.
- **전환:** 13→14번(현재 → 옛날)은 화면 전체가 스티커처럼 뜯겨 넘어간다(gfxPeel). 6번 뒤 제목 카드는 딱지가 뽑은 큰 스티커.
- **말하는 연기:** 대사 줄에서는 발음에 맞는 입(이·혀 포함), 강세에서 눈썹, 말 시작 전 들숨. 듣는 사람은 가끔 끄덕이고 시선은 말하는 사람에게.
- **규칙:** 폰 화면은 제로 시점(두 손 + 폰)에서만, 누르는 손가락 없음(글자는 저절로, 보내기는 눌림 표시). 붓다 · 종교 상징 없음(스님은 삭발 + 황토색 가사, 왕은 망토 + 흰 머리띠). 실제 깃발 · 문장 · 브랜드 없음. 죽음 장면 없음. 채널명은 제목 카드만.

## 4. 소리
- 배경음(Lyria, 노래 목소리 검사): 밤(조용한 로파이 건반) / 회의실(가벼운 피치카토) / 사갈라(탄푸라 지속음 + 대나무 피리 + 손북, 종교 음악처럼 들리지 않게).
- 효과음(`zw/gf_sfx.py` 합성): 폰 입력 틱, 답 칩 pop, 인쇄 '찌익'(새로 합성), 스티커 '탁'(stamp), 리모컨 미끄러짐, 부품 분리 pop(수레가 굴러오는 소리는 뺌: 수레는 처음부터 서 있다), ✕ 도장, 철컥(strike + ding), 이름표 item.
- 스테레오: 대사는 화면 위치에 따라 살짝 좌우로, 사갈라 마당은 얕은 울림. 효과음도 화면 위치로.
- 공기 소리(v2): 밤 방의 낮은 웅웅 / 회의실 환기 / 마당 바람. 배경음보다 13~14dB 작게, 말소리 띠 아래로. 28번 앞 침묵에는 바람 한 줄기(오른쪽 → 왼쪽).
- 말 여유(v2): 줄마다 말소리 띠에서 목소리가 배경음보다 12dB는 크게(모자란 줄만 배경음을 더 낮춘다. 17번 줄은 음악이 부풀어 6.3dB였다). 낱말 위의 효과음은 목소리보다 6dB 이상 작게, 겹치는 소리는 낱말 뒤로(`long/mask_ml.py`로 잰다).
- 자막(v2): 목소리를 따라 글자가 진해진다. 장면과 따로 뽑아 얹는다(`long/sub_ml.py`).
