# 시즌 1 · 1편 제작 안내 (회식 2차, 아무도 가고 싶지 않았다)

새 형식(`FORMAT.md`)의 첫 시범작입니다. 대본은 `script.py`, 읽기용은 `script_read.md`, 점검·읽기용 생성은 `python3 tools/script_tools.py ep01_hoesik/script.py --read`.

- **길이:** 추정 약 8:27. 미드롤 광고 후보는 2막 끝("…전혀 다르게 들렸습니다." 뒤, 약 5:15).
- **이 편의 장치:**
  - 화면 구석 카운터 `집에 가고 싶은 사람 n/5` (1 → 2 → 3 → 4 → 5). 숫자가 오를 때 작은 효과음.
  - 탬버린: 밤새 아무도 안 들다가, 마지막에 팀장이 한 번 흔듦. 11편(팀장의 탬버린)으로 이어지는 소품.
  - 제로의 휴대폰 임시 보관함 메일(출판사 답장): 시즌 피날레(12편)의 복선. 화면에 1~2초만.
- **새 목소리(시즌 내내 고정):** 오 팀장(40대 후반 남, 낮고 서글서글), 박 과장(40대 초 여, 빠르고 다정), 한 주임(30대 초 남, 밝은 하이톤 / 화장실 장면은 지친 톤), 민지(20대 중 여, 조심스러운 말투). 후보 2~3개씩 운영자에게 먼저 들려 줍니다.
- **새 효과음:** door, mic_feedback, music_stop, tambourine, crowd_laugh, subway. 노래방 노래는 가사 없이 음표와 반주 느낌만(저작권).
- **새 감정 지시:** tired → "지치고 낮은".
