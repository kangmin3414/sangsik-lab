# 명함이 사라진 첫 월요일 — 화면 연출 v1

대본 `대본_v1.md`와 같은 줄 번호. 게임 감각 층(`zw/gf.js`) + 몰입 층(`zw/gfx.js`). 장면 코드 접두사는 `nc`.

## 0. 전체 약속
- **한 편을 꿰는 표시: 자막 이름표.** 대사 상자의 이름표가 곧 그 사람의 명함이다. 1~11번은 [팀장], 14번 "박정훈입니다"가 끝나는 순간 이름표가 한 번 비었다가(0.3초) [정훈]으로 새로 찍힌다. 그 뒤로 내레이션도 '팀장님' 대신 '정훈 씨'라고 부른다.
- **명함이(속 캐릭터):** 손바닥만 한 흰 명함에 눈 둘 · 짧은 팔다리. 정훈 씨 재킷 안주머니에 산다. 등장할 때는 늘 두 손을 모으고 90도로 인사한다(명함을 두 손으로 건네는 모습). 1~3번까지는 얼굴 자리에 글자("영업2팀 팀장 박정훈", 회사 이름 · 로고 없음)가 있었다는 것을 4번 첫 프레임 0.2초로만 보여 주고, 곧바로 글자가 증발해 하얀 얼굴만 남는다. 25번에서 나무 이름표 위에 올라앉으면 몸이 나뭇결 무늬로 바뀐다.
- **마을 사람들(목공방 강사 · 수강생):** 목소리 대신 말풍선 + 게임식 옹알이(사람마다 높이가 다른 짧은 소리, 글자 수만큼). 둥근 회색 머리의 스틱맨, 앞치마.
- **게임 장치:** 자기소개 = 차례 화살표(동그랗게 앉은 사람들 머리 위를 돈다), 빈칸 스무 개 = 12:00 타이머가 달린 답안 카드, 직함이 사라짐 = 글자 증발, 관계로 불림 = 연락처 이름 바뀜(제로 시점).
- **빛:** 월요일 새벽은 푸르스름한 현관등, 목공방은 큰 창의 오전 햇빛 + 떠다니는 톱밥, 밤은 스탠드 하나, 여섯째 주는 같은 목공방이지만 조금 더 따뜻하게.
- **규칙:** 기기 화면은 그 사람 시점(두 손 + 폰)에서만, 누르는 손가락 없음(글자는 저절로, 보내기는 눌림 표시). 회사 이름 · 로고 없음. 채널명은 제목 카드만. 끝인사 없음.

## 3. 소리
- 배경음(Lyria, 노래 목소리 검사 VAD 0): 새벽(조용한 피아노 두 음) → 목공방(가볍고 나무 같은 마림바 + 어쿠스틱 기타) → 밤(같은 선율을 피아노 하나로) → 여섯째 주(목공방 곡, 조금 더 밝게).
- 효과음(직접 합성): 알람, 단추 · 넥타이 스침, 글자 증발(짧은 '샤르륵'), 인사 '톡', 메시지 도착 '똑', 입력 중 점 셋(아주 작게), 차례 화살표 회전 + 멈춤 '띵', 마을 사람 옹알이(사람마다 높이 다르게, 글자 수만큼), 나무 이름표 받는 '딱', 타이머 똑딱(15번만), 의자 '삐걱' · '덜컥', 인두 '치익'(25번 앞 잠깐), 이름표 바뀜 '톡'.
