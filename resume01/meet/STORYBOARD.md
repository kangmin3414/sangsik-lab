# 회의 장면 샘플 콘티 (대본_v4 17~22번, 35.7초)

완성본 v1의 같은 대목(15~16번, 7.5초)은 "질문 한 줄 → 침묵"이었다. 이 판은 발표가 막히는 과정을 장면으로 보여 준다.
바꾼 것 세 가지: ① 대사가 오가고 3~5초마다 샷 크기가 바뀐다 ② 노란 한 줄이 몸으로 방해한다 ③ 음악이 조여 오다가 한 줄이 입을 덮는 순간 뚝 끊긴다.

| 줄 | 말 | 화면 | 샷 | 트리거 |
|---|---|---|---|---|
| m0 | (말 없음 1.8초) | 회의실 전체. 제로가 리모컨을 들고 화면 옆에 선다. 어깨에 작은 노란 한 줄 | 전체, 천천히 밀기 | 리모컨 '딸깍' 1.2초 |
| m1 | 제로 "…그래서 이번 분기 매출이, 30퍼센트 오른 것으로…" | 말하는 제로 → 화면의 막대가 솟고 '+30%' → 리모컨을 쥔 손이 떨린다 | 전체 → 화면 인서트 → 손 인서트 | "30" |
| m2 | 고객사 "잠깐만요. 이 30퍼센트, 기준이 뭐죠? 전년 대비예요, 전 분기 대비예요?" | 펜을 든 담당자 → 담당자 어깨 너머로 본 제로(한 줄이 '쿵' 무거워진다) → 눈이 흔들리는 제로 | 얼굴 → 어깨 너머 → 얼굴 | "뭐죠" 뒤, "전 분기" |
| m3 | 제로 "그게… 전체적으로, 그러니까… 종합적으로 봤을 때…" | 더듬는 제로, 한 줄이 커지며 어깨가 내려앉는다 → 전체: 한 줄에 눌려 숙인 제로, 동료가 팀장을 본다 | 얼굴 → 전체 | "종합적으로" |
| m4 | 고객사 "이 툴, 직접 써 보신 거 맞죠?" | 펜을 내려놓고 조용히 묻는다 | 얼굴, 천천히 밀기 | |
| m5 | (말 없음 3.8초) | 제로가 입을 연다 → 어깨의 한 줄이 올라와 입을 덮는다 → 전체: 모두 제로를 본다, 팀장이 자료를 덮는다 | 얼굴 → 전체(멈춤) | 0.75초, 2.05초 |
| m6 | 팀장 "…제가 이어서 설명드리겠습니다." | 팀장이 일어선다, 손을 내민다 | 중간 샷 | |
| m7 | (말 없음 1.6초) | 제로가 한 걸음 물러난다 | 전체 | |

소리: 에어컨·프로젝터 소리가 내내 깔린다. 음악(`bgm/tense.mp3`)은 조여 가다가 m5의 0.95초에 끊기고, 그 뒤는 시계 소리뿐이다. 효과음: 리모컨, 의자 삐걱, 펜, 한 줄이 무거워지는 '쿵', 심장 소리, 입을 덮는 '착'.
