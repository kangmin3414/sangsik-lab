# '만약에, ○○처럼 산다면?' — 현대인에게 옮긴 철학자의 지침 12 (2026-11-15)

- 앞 목록 `topics_ifphilo_11_2026-11-15.md`는 생활 습관·건강 쪽으로 기울어서 다시 짰다. 앞 목록은 지우지 않는다.

  1. 현대인의 순간(훅)
  2. 철학자의 이야기(이력 꼬리표, 결정적 일화)
  3. "만약에, ○○처럼 ~한다면?"
  4. 지침 넷: 철학자의 말 → 제로가 오늘에 해 봄 → 연구 → 큰 숫자 카드
  5. 솔직한 대목(그 철학자의 모순·한계)

  7. 끝 문장과 질문

- 연구가 이미 쓴 것과 겹치는지 저장소에서 찾았다.

## 추천 3

### 1. 「만약에, 원효처럼 '마음먹기'로 산다면?」
- **훅:** 똑같은 회사, 똑같은 일인데 어떤 날은 지옥이고 어떤 날은 괜찮다.
- **이야기(확인함, 서울신문 2018-05-12):**
  - 의상과 함께 당나라 유학을 떠났다. 비를 피해 들어간 토굴이, 날이 밝고 보니 해골이 있는 옛 무덤이었다. 다음 날 밤에는 귀신이 나타났다.
  - 원효는 "마음 밖에 따로 법이 없다"며 유학을 그만두고 돌아온다. 이 이야기는 『송고승전』 의상전에 있다.
  - 우리가 아는 '해골물'은 『종경록』에 실린 다른 판본이다. 영상에서는 '전해지는 두 이야기'로 소개한다.
- **지침:**
  1. **모든 것은 마음이 짓는다** → Plassmann 외 2008 PNAS(확인함): 같은 와인에 5달러·45달러 가격표를 붙였더니 비싼 쪽을 더 맛있다고 했고, 즐거움을 느끼는 뇌 영역(내측 안와전두피질)도 더 반응했다. 가격표 없이 다시 마시자 차이가 사라졌다.
  2. **어려운 말 대신 누구나 아는 말로**(저잣거리의 노래) → '지식의 저주' 손가락 박자 실험(Newton 1990, 확인 예정)
  3. **틀을 넘어서 살기**(무애) → 확인 예정
  4. **떠나지 않아도 깨달을 수 있다**(배도 타기 전에 깨달음) → '어딘가 가야만 바뀐다'는 생각 → 확인 예정
- **솔직한 대목:** 같은 밤을 보내고도 의상은 혼자 떠났다. 둘 다 길이었다.
- **왜 추천:** 한국 철학자, 누구나 아는 이야기의 원래 판본이라는 반전, 와인 실험 하나로 '마음먹기'가 눈에 보인다.

### 2. 「만약에, 에리히 프롬처럼 '갖기' 대신 '되기'로 산다면?」
- **훅:** 택배 상자를 뜯는 3초가 제일 행복하고, 그다음은 금방 시들해진다.
- **이야기(확인 예정):** 나치를 피해 망명한 정신분석가이자 사회철학자다. 『자유로부터의 도피』(1941)에서 "자유가 주어지자 사람들이 오히려 누군가에게 맡겨 버린다"고 썼다. 『사랑의 기술』(1956), 『소유냐 존재냐』(1976).
- **지침:**
  1. **소유가 아니라 존재로** → 물건보다 경험에 쓴 돈이 더 오래 행복했다(Van Boven & Gilovich 2003, 확인 예정)
  2. **사랑은 빠지는 게 아니라 배우는 기술** → 관계도 연습이 된다(확인 예정)
  3. **자유로부터 도망치지 않기**(남이 정해 주길 바라는 마음) → 확인 예정
  4. **혼자 있을 줄 알아야 함께할 수 있다** → 혼자 있는 시간의 질(확인 예정)
- **왜 추천:** 소비·연애·선택 피로라는 지금의 고민에 바로 붙는다. 저장소에서 아직 쓰지 않은 연구들이다.

### 3. 「만약에, 루소처럼 남과 비교하지 않는다면?」
- **훅:** 자기 전 인스타를 넘기다 보면, 내 하루만 초라해진다.
- **이야기(확인 예정):**
  - 감옥에 갇힌 디드로를 만나러 걸어가던 길에 번뜩인 생각으로 쓴 논문이 상을 받으며 유명해졌다(1750).
  - 『인간 불평등 기원론』에서 '자기애'와 '자존심'을 나눴다. 자존심은 남의 눈으로 나를 재는 마음이다.
  - 노년에는 『고독한 산책자의 몽상』을 썼다.
- **지침:**
  1. **남의 눈으로 나를 재지 않기**(자기애 vs 자존심) → SNS에서 위를 보고 비교할수록 자존감이 떨어졌다(Vogel 외 2014, 확인 예정)
  2. **혼자 걷기·몽상** → 자연 산책 뒤 반추가 줄었다(Bratman 외 2015 PNAS, 확인 예정)
  3. **책보다 경험으로 배우기**(『에밀』) → 확인 예정
  4. **자연스러운 감정을 믿기** → 확인 예정
- **솔직한 대목:** 아이 교육서를 쓴 그가 자기 아이 다섯을 고아원에 보냈다(『고백록』, 확인 예정). 철학이 삶을 다 구하지는 못한다는 005의 솔직함과 같은 자리다.
- **왜 추천:** 'SNS 비교'는 지금 현대인의 가장 흔한 고민이다. 300년 전 개념 하나가 정확히 들어맞는다.
