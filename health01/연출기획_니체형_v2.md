## 2. 이번 편: 「만약에, 니체처럼 몸을 돌본다면?」

- **훅이 되는 역설:** 평생 두통과 눈병에 시달린 철학자가, 자기 건강 수칙을 책에 또박또박 적어 두었다. 『이 사람을 보라』(1888) 「나는 왜 이렇게 영리한가」.
- 제로가 콧수염을 붙이고 그 수칙을 하루에 하나씩 따라 한다.
- **채점이**(빨간 색연필)가 오늘의 연구로 니체의 수칙을 채점한다: ○ 맞았다 / △ 반만 / ✕ 틀렸다.
  - 005의 '연구가 답한다'를 인물로 만든 것이다. 대본 v1부터 있던 채점이를 그대로 살린다.
- 니체가 다 맞지는 않는다. **커피에서 ✕**가 나오는 것이 이 편의 반전이다.

|---|---|---|---|---|

| 4일 차 | "커피는 끊어라. 커피는 사람을 우울하게 만든다." | 아침 커피를 끊고 오후에 멍해진 제로 | Lucas 2011(여성 50,739명, 평균 63세): 카페인 커피 하루 4잔 이상인 사람의 우울증 위험이 거의 안 마시는 사람보다 20% 낮음. 디카페인은 차이 없음. 연구진은 "더 마시라고 권하기는 이르다" | ✕ (니체가 틀렸다) |

- 대본 v1의 **종합비타민**은 니체 수칙에 없어서 뺀다(쇼츠나 다른 편으로 돌림).
- 1일 차는 005의 1장(걸으면서 생각하기, 창의성 +60%)과 같은 인용을 쓴다. **"지난번엔 머리, 이번엔 몸"**으로 이어 받아 겹침을 장점으로 쓴다.

## 4. 장 하나의 순서 (005 그대로 + 채점이)

1. **장 배지:** 「니체의 수칙 1/4 · 1일 차 · 앉지 말고 걷기」 (005의 '실험 1/5' 자리)
2. **니체의 말:** 큰 인용 제목 + 출처 알약(「— 니체, 『이 사람을 보라』(1888)」). 세피아 손글씨
3. **니체의 삶 한 조각:** 실스마리아 산길, 토리노의 하숙방 등. 확인된 사실만
4. **제로가 오늘에 해 봄:** 콧수염 제로의 짧은 장면 2~3컷, 제로 대사 한 줄
5. **채점이:** "근거는?" 하고 연구 카드를 꺼낸다(기관·인원 꼬리표)
6. **큰 숫자 카드:** 「41%」「1~6L」「두 잔」「−20%」 + 출처 한 줄(005의 「+60%」 카드)
7. **채점 도장:** 빨간 ○/△/✕가 쾅. 한 줄 정리

## 5. 화면

- **화풍:** 기본안은 지금 만든 **마커 종이 + 엔진 인물**. 005의 장치(이력 꼬리표, 인용 제목 + 출처 알약, 장 배지, 연구 카드, 큰 숫자 카드)를 마커 손글씨와 종이 꼬리표로 다시 그린다.
  - 다른 안: 005처럼 **AI 그림 배경**(알프스·토리노·밤 방) 위에 엔진 인물. 005의 따뜻한 그림 맛이 그대로 산다. 운영자 결정(8절).
- **콧수염 제로:** 엔진 제로에 니체 콧수염만 붙인다(005와 같은 얼굴). 붙일 때 '뿅', 뗄 때 주머니에.
- **니체:** 엔진 `NZ`(넘긴 머리, 팔자 콧수염, 짙은 코트). 실존 인물 사진·초상은 쓰지 않는다.
- **색:** 검정 = 뼈대, 파랑 = 연구, 빨강 = 채점(○△✕, 마지막 획), 세피아 = 니체의 말.
- **기기:** 워치·폰 화면은 제로 시점에서만. 손가락으로 누르는 장면은 없다.

## 6. 소리·목소리·템포

- 내레이터 Schedar, 제로 Puck, 채점이 Sadachbia(확인 대기). 005처럼 내레이션이 길을 잡되, 장마다 제로·채점이 대사를 1~2줄 넣는다(내레이션 약 65%).
- 니체는 말하지 않는다. 니체의 말은 화면 글씨 + 내레이션으로 전한다(005와 같음).
- 녹음은 늘이지 않고(기계음 방지), 줄 사이 0.15초.
- 채점 도장 '쾅', 콧수염 '뿅', 마커 사각거림. 배경음은 Lyria로 새로(밤 / 알프스 산책 / 토리노 / 끝).
