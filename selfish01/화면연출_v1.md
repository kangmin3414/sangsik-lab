# 자리를 양보했더니, 가슴에서 영수증이 나왔다 — 화면 연출 v1

대본 `대본_v1.md`와 줄 번호로 맞춘다. 제작 방식은 걱정 편(`worry01/long/`)과 같다: 스틱맨 + SVG 세계, 3~5초마다 컷, 단어 시각에 맞춘 동작.

**공통 규칙**
- 기기 화면은 나오지 않는다. 지하철 노선 번호·역 이름·광고판 글자는 넣지 않는다(안내판은 색 띠만).
- 책은 민무늬 표지에 제목 글자만. 실제 표지 디자인과 저자 얼굴은 그리지 않는다.
- 영상 안에 끝인사·로고는 넣지 않는다. 채널명은 타이틀 카드(1.8초)에만.
- **색:** 지하철은 따뜻한 저녁 조명(크림색 벽, 주황 손잡이). 책 속 세계는 걱정 편처럼 밝게: 청록에서 연보라로 넘어가는 하늘, 금빛 사슬. 어두운 배경은 쓰지 않는다.
- **계산이:** 제로 가슴 문에서 나오는 꼬마 회계 담당. 초록 챙(회계사 모자)에 팔 토시, 배에 작은 영수증 프린터가 달려 있고 귀 뒤에 연필을 꽂았다. 신나면 프린터가 빨리 돌고, 풀이 죽으면 종이가 축 늘어진다.
- **영수증:** 흰 종이에 항목은 짧은 화면 글자로(예: '뿌듯함 3 / 시선 2 / 귤 2'). 한 화면에 세 줄까지만.
- **배경음:** 훅은 가벼운 피치카토. 책 속은 신비로운 하프·벨. 20~22번에서 멈칫(음악이 얇아짐). 23~26번 경쾌한 대회 음악. 33~37번 조용한 피아노. 결말은 따뜻한 현악, 41번에서 넓어진다.
