## 1. 지금 엔진에서 보이는 문제 (디오게네스 샘플 QA에서 나온 것)

| # | 보이는 문제 | 원인 |
|---|---|---|
| 1 | 걸을 때 발이 땅 위를 미끄러진다(스케이트) | `walkPose`가 시간으로 다리를 흔들 뿐, 몸이 간 거리와 발이 연결돼 있지 않다 |
| 2 | 포즈가 바뀌는 중간에 팔이 줄었다 늘었다 한다(고무 팔) | `mixPose`가 관절 좌표를 직선으로 섞는다 |
| 3 | 동작이 뚝 시작해서 뚝 멈춘다(로봇 같음) | 예비 동작·지나침·안착이 없다 |
| 4 | 손이 늘 동그라미, 물건이 손 옆에 떠 있다(컵·지팡이·폰) | 손 모양이 하나뿐이고, 물건 좌표를 손과 따로 계산한다 |
| 5 | 고개를 돌릴 때 눈·머리·몸이 한꺼번에 돈다 | 시선 순서가 없다 |
| 6 | 던지기가 순간이동처럼 보인다 | 와인드업·궤적·충격 표현이 없다 |
| 7 | 망토·배낭·머리카락이 몸에 붙어 굳어 있다 | 늦게 따라오는(관성) 표현이 없다 |
| 8 | 점프·착지가 위아래 이동뿐이다 | 웅크림·늘어남·찌그러짐이 없다 |

## 2. 기법과 쓰는 법

### ① 발이 붙는 걷기 — `A2.walk(t, {x0, x1, t0, t1, s, step, lift, bob, lean})`
- 디딘 발은 땅에 고정, 몸이 그 위를 지나간다. 디딘 동안 발 이동은 프레임당 0.6px 이하(측정값).
- 출발·정지 22% 구간 가감속, 첫·마지막 반걸음은 발을 낮게 든다(정지 때 발 끌림 없음).
- 두 발이 벌어질 때 몸이 가장 낮다(bob), 속도만큼 앞으로 기운다(lean), 머리는 진행 방향으로 3/4 돌아간다(turn).
- 반환 `{x, pose, rot, turn, moving, dir}` → `char({x: q.x, pose: q.pose, rot: q.rot, turn: q.turn, ...})`.
- 점검: 비교 영상 ①처럼 디딘 발 자리에 점을 찍어 본다. 점이 줄이 되면 미끄러진 것.

### ② 뼈 길이 고정 팔다리(IK) — `A2.pose({hL, hR, fL, fR, dy, bend})`, `A2.blend(a, b, k, arc)`
- 손·발 위치만 주면 팔꿈치·무릎을 계산한다. 팔(65+62)·다리(58+52) 길이가 절대 변하지 않는다.
- `dy`로 몸을 낮춰도 발은 그 자리(무릎이 굽는다). 웅크림·앉기·짐 들기에 쓴다.
- `blend`는 손을 직선이 아닌 바깥으로 휘는 호(arc)로 옮긴다. 사람 팔은 원을 그리며 움직인다.
- 손이 닿지 않는 곳을 주면 팔이 뻗을 수 있는 데까지만 간다(늘어나지 않음).

### ③ 예비 동작 + 지나침 + 안착 — `A2.actK(t, t0, dur, {antic, anticAmt, over, settle})`
- 0 → 1 진행값. 시작 0.14초 전 반대쪽으로 12% → 주 동작(감속 곡선) → 10% 지나침 → 0.35초 동안 출렁이며 안착.
- 쓰는 곳: 가리키기, 손 흔들기, 돌아보기, 일어서기, 놀람. 큰 동작일수록 anticAmt를 키운다(놀람 0.25, 던지기 0.35).

### ④ 손 모양 + 쥔 물건 — `char({handL, handR, holdL, holdR})`
- `handL/handR`: `'fist'`(주먹), `'grip'`(쥔 손), `'point'`(검지), `'thumb'`(엄지 척), `'open'`(편 손). 아래팔 방향으로 자동 회전.
- `holdL/holdR`: 손 중심 기준 SVG. `{svg, follow: true}`면 아래팔 방향으로 같이 돈다. 물건은 팔 위·손 아래 층에 그려져 손이 감싼 것처럼 보인다.
- 규칙: 손에 든 물건은 반드시 `hold`로 붙인다. 따로 좌표를 계산하지 않는다(디오게네스 컵·지팡이 문제의 원인).

### ⑤ 눈 → 머리 → 몸 순서 — `look`, `turn`, `rot` + `A2.follow`
- 눈(look)이 먼저, 0.1초 뒤 머리(turn·tilt), 0.2초 뒤 몸(rot). 같은 신호를 `A2.follow`로 다르게 늦춰 쓴다.
- `turn`(-1~1)은 얼굴 부위를 옆으로 옮겨 3/4 얼굴을 만든다(기본값 0이면 예전과 같음).

### ⑥ 빠른 동작 — 와인드업, `A2.swoosh`, `A2.ghost`, 포물선, `A2.squash`, `A2.shake`
- 던지기 순서: 웅크리며 뒤로 감기(0.3초) → 빠른 휘두름(0.12초, 스우시 궤적 + 잔상 3장) → 놓는 순간 물건은 포물선 + 회전 → 닿을 때 찌그러짐·튕김 + "탁" 글자 + 카메라 흔들림 0.35초.
- 효과음은 '놓는 순간'과 '닿는 순간' 두 번(디오게네스 샘터 장면 기준).

### ⑦ 늦게 따라오는 것들 — `A2.follow(fn, t, f, z, win, n)`
- 몸의 움직임 신호(속도, 오르내림)를 스프링처럼 늦게, 출렁이며 따라간다. 시간 t만으로 계산하므로 프레임을 나눠 병렬 렌더해도 결과가 같다.
- 목도리·망토: 마디마다 조금씩 더 늦게 → 채찍처럼 휜다. 걸으면 뒤로 날리고, 멈추면 앞으로 한 번 넘어갔다 돌아온다.
- 머리카락·배낭·꼬리·수염·끈: 같은 방법. 주파수 f가 낮을수록 무겁고 느리다(추천값: 배낭 1.0, 목도리·망토 1.3, 머리카락 2.4).

### ⑧ 점프·착지
- 웅크림(0.25초, 무릎 굽힘) → 공중에서 세로로 12% 늘어남 + 다리 접기 + 팔 벌림 → 착지 0.3초 찌그러짐(가로 약 15%) + 먼지 → 목도리 끝이 위로 튀었다 내려옴.

## 3. 물리 점검표에 더할 규칙
1. 걷는 장면은 `A2.walk`만 쓴다. 발자국 점검(점이 줄이 되면 실패).
2. 포즈 사이 전환은 `A2.blend`(뼈 길이 고정). `mixPose`는 아주 짧은 전환에만.
3. 0.5초 넘는 큰 동작은 예비 동작 없이 시작하지 않는다.
4. 손에 든 물건은 `holdL/holdR`. 손 모양은 쥐면 `grip`, 가리키면 `point`.
5. 돌아보기는 눈 → 머리 → 몸.
6. 천·머리카락·배낭은 `A2.follow`로 늦게 따라오게.

## 4. 다음 편에 쓰는 곳

**디오게네스 2막~결말**
- 배낭: 걸을 때 위아래로 늦게 출렁, 내려놓을 때 '쿵' 찌그러짐(①⑦⑧).
- 알렉산드로스 망토: 말에서 내려 걸어올 때 뒤로 날림, 멈추면 앞으로 넘어감(⑦).
- 지팡이·컵·자루: 전부 `holdR/holdL`(④). 디오게네스가 왕을 가리키는 손은 `point` + 예비 동작(③).
- 결말 벤치: 팀장이 배낭을 내려놓는 동작은 IK로 무릎을 굽혀 내려놓기(②).

**반쪽 편(『향연』)**
- 둥근 사람 공중제비: 바퀴처럼 굴러가는 회전 + 착지 찌그러짐(⑧).
- 붙은 두 사람이 서로 다른 쪽으로 걸으려다 넘어짐: `A2.walk` 두 개를 반대 방향으로 돌리고, 몸통 연결부를 당기다 '쿵'(①⑥).
- 아리스토파네스 재채기: "에… 에…" 동안 크게 뒤로 젖히는 예비 동작 → "취!" 지나침 + 카메라 흔들림(③⑥). 제로가 든 깃털은 `holdR` + `grip`(④).
- 반쪽이(배꼽에서 나온 꼬마): 머리카락·꼬리를 `follow`로 늘 살짝 늦게(⑦).

## 5. 아직 안 된 것 (다음 단계 후보)
- 몸통 3/4 회전: 지금은 머리만 돌고 몸통은 정면.
- 입 모양: 지금 `talk`는 일정한 속도로 열고 닫는다. 음성 크기(RMS)를 프레임마다 읽어 `talk` 숫자로 넣으면 말에 맞게 열린다.
- 걷기 종류: 지친 걸음(발 끌기), 신난 걸음(통통), 몰래 걷기(무릎 높이)를 `A2.walk` 옵션으로.
- 12fps 느낌(on twos): 동작만 1/12초마다 바꾸는 손그림 느낌 옵션. 선 떨림(boil)은 이미 1/12초.
