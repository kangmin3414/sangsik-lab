## 1. 캐릭터 원칙: 귀여움 공식

1. **큰 눈 + 하이라이트 두 개.** 눈 크기를 지금보다 약 1.5배로 키우고, 흰 점을 큰 것 하나, 작은 것 하나 넣습니다. 생기가 가장 크게 달라지는 부분입니다.
2. **볼터치 기본.** 평소엔 연하게, 감정이 올라가면 진하게 하고, 부끄러울 땐 빗금(///)을 넣습니다.
3. **둥근 것 우선.** 소품과 말풍선의 모서리를 둥글게 하고, 각진 선은 화·충격 장면에만 씁니다.
4. **실루엣은 지킨다.** 큰 둥근 머리, 주황 티, 막대 팔다리는 제로의 정체성이라 유지합니다. 얼굴과 연기만 바꿉니다(몸 비율 변경은 10번 '정해 주실 것' 참고).
5. **손님·조연도 같은 얼굴 규칙.** 색, 소품, 머리 모양으로만 구분하고, 표정 표현은 모두 같은 시스템을 씁니다.
6. **철학자는 상징 소품만.** 월계관, 콧수염과 망치, 상투와 수염, 흰 옆머리. 실존 인물의 얼굴은 쓰지 않습니다(기존 규칙).

### 1-1. 여자 캐릭터 기준 (첨부 `out/제로_여자캐릭터_v3.png`)

같은 몸(막대 팔다리, 둥근 손발)과 같은 표정 23종을 쓰고, 다음 요소로 귀여움과 매력을 냅니다.

- **헤어 6종:** 단발 보브(별 핀), 포니테일, 양갈래 똥머리(작은 리본), 긴 생머리(머리띠), 숏컷(삐침머리·귀걸이), 웨이브(베레모)
  - 머리 모양이 실루엣을 결정합니다. 그림자만 봐도 누군지 알 수 있게 합니다.
  - 머리색은 6가지(초코, 흑발, 밤색, 애쉬, 허니, 네이비)입니다.
- **흔들림:** 포니테일, 단발 끝, 리본, 귀걸이, 삐침머리는 몸보다 한 박자 늦게 흔들립니다(엔진에 반영).
- **얼굴:**
  - 눈꼬리 위쪽에 속눈썹 두 가닥을 넣습니다. 눈이 감긴 표정(^^, 엉엉)에서는 자동으로 빠집니다.
  - 눈썹은 남자 캐릭터보다 얇게 그립니다(굵기 13 → 8).
  - 볼터치는 조금 더 진하게 합니다.
  - 입술 색은 넣지 않습니다.
- **옷:** 파스텔 두 색 조합으로, 티에 치마 또는 바지를 입힙니다. 나이와 성격은 머리, 색, 소품으로 표현합니다.
- **하지 않는 것:** 몸매 강조, 노출, 과장된 포즈. 성인 인물은 대본 나이 그대로 성인으로 그립니다.
- **연기:** 몸짓은 남녀 같은 연기 원칙을 씁니다. 성격 차이는 걸음걸이와 리액션 크기로 냅니다.
- **혈액형 편 AB형 손님(여자):** 방호복 후드 안으로 단발 앞머리, 속눈썹, 볼터치가 보이게 했습니다. 바이저는 더 투명하게 해서 표정이 보이게 합니다.

## 2. 표정 시스템 v3 (표정 시트 참고)

**23종, 6가지 계열**
- **기쁨:** 기본, 반짝(기대), 하트눈(반함), 빵긋(신남), 설렘(칭찬), 뿌듯(해냄)
- **장난:** 히죽(꿍꿍이), 메롱
- **당황:** 당황(들킴), 민망(머쓱), 의심(갸웃), 멍(머리 정지)
- **슬픔:** 울먹(울기 직전), 엉엉(폭풍 눈물), 삐짐(서운)
- **화·충격:** 버럭, 충격(뼈 맞음), 소름, 멘붕, 기절
- **기타:** 결심(불타는 눈), 졸음(콧방울), 하품

**표정 연출 규칙**
1. **한 줄에 두 번 이상.** 대사 한 줄 안에서 표정이 최소 두 번 바뀝니다. 시작 표정에서, 핵심 단어가 나올 때 반응 표정으로 넘어갑니다. 전환 시점은 단어 타이밍에 맞춥니다.
2. **그냥 갈아 끼우지 않는다.** 표정 전환은 두 가지 방식으로 합니다.
   - 깜빡 전환: 눈을 감았다 뜨면서 바뀜. 조용한 감정에 씁니다.
   - 팝 전환: 머리가 6% 부풀었다 돌아오며 바뀜. 놀람이나 기쁨에 씁니다.
3. **눈으로 생각하기.** 생각할 땐 시선이 위로, 피할 땐 옆으로, 확신할 땐 정면으로 갑니다. 깜빡임은 3~5초마다 무작위로 하고, 감정이 바뀔 땐 두 번 연속 깜빡입니다.
4. **입 모양 4단계(립싱크 v2).** 닫힘, 작게 벌림, 크게 벌림(ㅏ), 둥글게(ㅗ·ㅜ) 네 가지입니다. 녹음에서 뽑은 단어 시각과 대본 글자로 음절마다 모음을 추정해서 모양을 고르고, 크기는 소리 크기로 정합니다.
5. **기호가 감정을 한 번 더 말한다.** 표정마다 짝이 되는 만화 기호(4번 표)를 함께 띄웁니다.

## 3. 연기 원칙 (모든 인물, 모든 컷)

1. **예비동작.** 큰 동작 전엔 반대 방향으로 약 4프레임(0.17초) 움찔합니다. 뛰기 전에 웅크리고, 던지기 전에 뒤로 젖힙니다.
2. **찌그러짐·늘어남.** 놀람, 점프, 착지, 웃음에서 몸 높이를 0.88~1.14배로 바꿉니다. 부피는 유지해서, 세로로 늘면 가로는 줄입니다.
3. **반동.** 멈출 때 한 번 지나쳤다가 돌아옵니다. 착지, 고개 돌리기, 팝업 등장 모두 해당합니다.
4. **따라오는 움직임.** 후드 끈, 보따리, 머리카락, 들고 있는 물건은 몸보다 한 박자 늦게 움직입니다.
5. **대기 연기.** 말하지 않는 인물도 3~4초마다 작은 행동을 합니다. 숨쉬기와 깜빡임에 더해 고개 갸웃, 발 까딱, 시선 이동, 손가락 꼼지락 등입니다. 화면에 완전히 멈춘 인물이 없게 합니다.
6. **리액션 우선.** 펀치라인, 진단명, 명언 뒤에는 반드시 듣는 사람의 얼굴을 0.6~1초 보여 주는 리액션 컷을 넣습니다.
7. **걸음걸이 3종.** 종종걸음(귀여움, 기본), 터덜터덜(지침), 깡총(신남)입니다. 미끄러지듯 이동하는 건 금지합니다.
8. **홀드.** 중요한 표정은 최소 12프레임(0.5초) 동안 그대로 둬서 읽히게 합니다. 멈춘 동안에도 숨은 쉽니다.

**리액션 묶음(자주 쓰는 연기 단위)**

| 이름 | 흐름 | 길이 |
|---|---|---|
| 깜짝 | 평소 → 움찔(웅크림) → 튀어오름(늘어남·충격) → 정점(충격선) → 착지(찌그러짐) → 반동 → 정착(당황·땀) | 22프레임 ≈ 0.9초 (리액션 시트) |
| 털썩 | 휘청 → 무릎 꺾임 → 바닥에 납작(찌그러짐) → 영혼 빠짐 | 1.2초 |
| 버럭 | 몸이 부풀며 빨개짐 → 김 뿜기 → 분노 마크가 쿵쿵 | 1초 |
| 시무룩 | 어깨가 내려가며 몸이 0.92배로 쪼그라듦 → 그늘선 | 1초 |
| 반짝 | 머리가 뿅 튀어나옴 → 별 눈 → 반짝이 | 0.6초 |
| 도리도리·끄덕 | 고개를 좌우·상하로 3번 흔들며 점점 작게 | 0.8초 |
| 꾸벅 | 숙였다 반동하며 올라옴 | 0.7초 |

## 4. 만화 기호 라이브러리 + 짝 효과음

| 기호 | 쓰는 순간 | 효과음(직접 합성) |
|---|---|---|
| 땀방울 | 당황, 긴장 | 똑 |
| 그늘선(보라 세로줄) | 충격, 우울 | 낮은 '둥' |
| 분노 마크 | 화 | 뿌직 |
| 김 모락모락 | 버럭 | 칙 |
| 반짝이 별 | 기대, 뿌듯 | 띠링 |
| 하트 | 설렘, 반함 | 뿅 |
| 물음표·느낌표 팝 | 의문, 깨달음 | 띠용 / 띵 |
| 충격선·집중선 | 큰 깨달음, 뼈 맞음 | 촤악 |
| 소용돌이 눈 + 도는 별 | 멘붕 | 띠로리 |
| 콧방울 | 졸음 | 뽀글, 터질 때 팡 |
| 영혼 빠짐 | 탈진 | 휘익 |
| 눈물 폭포 | 엉엉 | 졸졸 물소리 |
| 먼지구름 | 착지, 퇴장 | 퐁 |

- 효과음은 귀여운 쪽(뿅·퐁·띠링)을 기본으로 하고, 묵직한 소리는 진단 도장과 충격에만 씁니다.
- **1초에 효과음은 최대 하나.** 내레이션 단어와 겹치면 0.3초 뒤로 미룹니다(혈액형 편 음성 인식 검사에서 겹침 사고가 있었음).

## 5. 카메라·편집 문법

- **컷 길이 2~4초.** 한 문장 안에서는 최대 2컷까지 씁니다.
- **샷 순환.** 전체, 어깨 너머, 클로즈업, 인서트(손·폰·물건)에 리액션 클로즈업을 더한 5종을 돌립니다. 같은 샷이 연속 3번 나오지 않게 합니다.
- **줌 펀치.** 핵심 단어에서 순간적으로 8% 줌인했다가 0.3초에 걸쳐 돌아옵니다. 한 편에 10번 이내로 씁니다.
- **장소가 바뀔 때만 전환 효과**를 씁니다. 원형으로 닫히기(아이리스), 휙 밀기, 문 열고 들어가기의 3종이고, 같은 장소 안에서는 하드컷입니다.
- **화면 흔들림**은 충격 순간에만 0.2초 넣습니다.
- **화면 글자**는 한 번에 하나만 띄우고 최소 1.5초 머무릅니다. 자막과 겹치지 않게 화면 위쪽 2/3 안에 둡니다.
- **색 흐름.** 하소연 장면은 차갑게, 처방 장면은 따뜻하게(이미 쓰는 따뜻한 조명) 하고, 막 사이 대비를 지금보다 조금 더 키웁니다.

## 7. 제작 방식 (엔진·작업 흐름)

**이미 반영한 것**
- 엔진에 표정 효과 층 3개를 추가했습니다: 볼 아래층, 눈과 함께 움직이는 층, 얼굴 위층. 기존 편에는 영향이 없습니다.
- 표정 23종: `zw/face2.js`
- 머리카락 층 3개(몸 뒤, 머리 뒤, 앞머리), 큰 눈용 속눈썹, 눈썹 굵기 옵션을 추가했습니다. 여자 캐릭터 프리셋은 `zw/girls.js`의 `zGirl()`입니다.

**만들 것** (반복 작업을 도우미로 바꿔서, 늘어나는 디테일을 손코딩 없이 처리)
1. `act()`: 리액션 묶음 이름과 시작 시각만 주면 찌그러짐, 반동, 표정 전환, 기호, 효과음을 자동으로 계산합니다.
2. `idle()`: 대기 연기를 무작위로 짜 줍니다(깜빡임, 시선, 갸웃, 발 까딱). 인물마다 시드가 달라서 똑같이 움직이지 않습니다.
3. 립싱크 v2: 입 모양 4종 + 음절 모음 추정.
4. 만화 기호 라이브러리 `zfx.js`: 기호를 넣으면 짝 효과음이 자동으로 효과음 목록에 들어갑니다.
5. 걸음걸이 3종, 장면 전환 3종.
6. **비트 시트 → 장면 자동 배치:** 콘티 표의 표정·기호·소리 칸을 읽어서 장면 코드에 자동으로 넣습니다. 손으로 쓰는 건 배경과 소품뿐입니다.

**점검(애니메이션 QA)에 추가할 항목**
- 대사 한 줄에 표정 변화가 2번 이상인가
- 펀치라인, 진단명, 명언 뒤에 리액션 컷이 있는가
- 2초 넘게 완전히 멈춘 인물이 없는가
- 기호와 효과음이 짝지어 나오는가
- 효과음이 내레이션 단어와 겹치지 않는가(음성 인식으로 다시 확인)
- **앉는 가구는 배경 그림에 넣지 않는다:** 소파·의자는 직접 그려서 층을 나눈다(등받이·받침은 인물 뒤, 쿠션 앞면·팔걸이는 인물 앞). 엉덩이는 쿠션에 묻히고, 짧아진 다리가 동동 흔들려야 앉은 것으로 읽힌다(피로사회 편 수정 사항).
- **작은 인물이 든 소품은 얼굴을 가리지 않는다:** 확성기 같은 소품은 손잡이를 쥔 손에 붙이고, 입 옆에서 바깥쪽을 향하게 한다. 머리가 큰 인물 어깨 위에 작은 인물을 세우면 볼을 가리므로 머리 꼭대기나 가구 위에 세운다.
- **발이 디딜 곳이 있는가:** 서 있는 인물은 바닥, 가구 윗면, 다른 인물의 머리·어깨 위에 정확히 발을 딛는다(공중에 뜬 위치 금지).

**작업량**
처음 도우미를 만드는 데 하루 정도 걸립니다. 그 뒤로는 한 편당 작업량이 지금과 비슷하거나 조금 더 드는 수준입니다.
