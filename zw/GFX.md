# 몰입 층 (zw/gfx.js · zw/gfx_mix.py)

운영자 요청(2026-11-22): "몰입감 있게 만들어 줘, 애니메이션 엔진도 향상시키고 재미있게 만들어 보자."
2026-11-14 엔진 점검(`plan/engine_review_2026-11-14.md`)에서 '엔진에 실제로 없는 것'으로 남아 있던 **빛 · 깊이 · 샷 문법**을 채우고, 말하는 연기와 타격감, 스테레오 소리를 한 층으로 묶었다.
엔진 본체(`shorts/engine.js`), 연기 층(`zw/act.js`), 게임 감각 층(`zw/gf.js`)은 그대로다. 새 이름은 모두 `gfx`로 시작한다. 첫 사용: 불교 편(수레 문답) `milinda01/long/mlgf.js`, `mlgf2.js`, `build_ml.py`.

## 무엇이 달라지나 (전 → 후)
| | 전 | 후 |
|---|---|---|
| 빛 | 인물 밝기가 어디서나 같아서 어두운 방에 흰 인물이 스티커처럼 떠 보였다 | 장면마다 주광 하나. 광원에 가까운 쪽이 밝고, 가장자리가 둥글게 살아나고, 빛이 오는 쪽에 테두리 빛이 돈다 |
| 그림자 | 발밑 타원 하나 | 벽에 드리운 큰 그림자(폰 빛), 바닥에 길게 눕는 그림자(저녁 해) |
| 공기 | 없음 | 창살·나뭇잎 사이 빛줄기, 떠다니는 먼지, 광원 번짐, 장면별 색 보정과 가장자리 어둡게 |
| 카메라 | 장면마다 손으로 짠 확대·이동 | 샷 키 목록 하나로. 늘 조금 떠다니고, 충격에 흔들리고, 배경·인물·앞 층이 다르게 움직이고, 클로즈업에서 배경이 흐려진다. 빠른 이동에는 가로 번짐 |
| 말 | 목소리 크기만큼 벌어지는 타원 입 | 모음에 맞는 입 모양 + 이·혀 + 강세에서 올라가는 눈썹 + 말 시작 전 들숨. 듣는 사람은 끄덕인다 |
| 타격감 | 고리·별 | 멈칫(그림만 0.1초 얼어붙음) + 충격 프레임 + 카메라 흔들림을 같은 시각에 |
| 소리 | 모노 | 스테레오. 대사와 효과음이 화면 위치를 따라 좌우에 놓이고, 장면 공간에 맞는 얕은 울림이 붙는다. 장면마다 공기 소리(밤 방 · 회의실 환기 · 마당 바람)가 깔리고, 음악이 부푼 대목에서는 그 줄만 배경음이 더 내려간다 |
| 자막 | 문장이 한꺼번에 뜸 | 목소리를 따라 글자가 진해진다(게임 대화창처럼). 장면과 따로 뽑아서 얹으므로 자막만 바꿀 때 장면을 다시 그리지 않는다 |
| 점검 | 축소한 시트를 눈으로 | 화면 끝에 조금만 걸친 머리, 효과음에 덮인 낱말, 너무 긴 컷을 스크립트가 숫자로 찾아 준다 |

## 켜는 법
- 페이지(`anim_*.html`)에서 `zw/gf.js` 다음에 `zw/gfx.js`를 읽는다(예: `milinda01/long/anim_ml.html`).
- 장면 함수는 **화면 좌표**로 그린다: 맨 바깥을 `gfxScreen(…)`으로 감싸면 render()의 0.88배 축소가 풀리고 1920×1080 좌표를 그대로 쓴다. `CAMS[장면] = 'fixed'`.
- 층 순서(권장, `mlCompose` 참고): 먼 배경(`gfxLayer` depth 0.1~0.9) → 그림자(`gfxCast`) → 빛 받는 인물·소품(`gfxLit` + depth 1) → 빛 번짐·효과(depth 1, 필터 없음) → 카메라 앞 층(depth 1.3~1.5, 흐림) → 색 보정·가장자리(`gfxGrade`, `gfxVignette`) → HUD.

## 함수
| 묶음 | 함수 | 쓰임 |
|---|---|---|
| 좌표 | `gfxScreen(inner)` | 화면 좌표로 그리기 |
| 카메라 | `gfxCam(keys, t)` | `[[t, {x, y, z, r}, {d, ease}], …]` → 지금 카메라. ease: io · out · in · lin · back · cut |
| | `gfxDrift(cam, t, amp, seed)` | 숨 쉬는 카메라(모든 샷에) |
| | `gfxShake(cam, t, [[t0, 세기, 길이], …])` | 충격 흔들림 |
| | `gfxLayer(cam, depth, inner, {blur, op})` | 깊이 층. blur는 2 · 4 · 7 · 12 |
| | `gfxProj(cam, x, y, depth)` | 세계 좌표 → 화면 좌표(조명 위치, 화면 밖 판정) |
| 빛 | `gfxDefs({lights: […], shadow})` | 필터 묶음(흐림·그림자·번짐 + 조명) |
| | 조명 `{id, amb, key: {x, y, z, col, k}, rim: {dx, dy, col, k}, bump, relief}` | amb = 그늘 색(곱), key = 점광원(화면 좌표, z가 클수록 넓게), rim = 빛이 오는 쪽 가장자리 |
| | `gfxLit(id, inner)` | 조명 씌우기(인물·소품 층에만. 배경은 처음부터 그 색으로 그린다) |
| | `gfxCast(inner, {cam, dx, dy, s, cx, cy})` / `{cam, floor, skew, len}` | 벽 그림자 / 바닥 그림자 |
| | `gfxGlow(x, y, r, col, op)` | 광원 번짐(화면·달·해) |
| | `gfxShafts(t, {x, y, ang, n, gap, w, len, op})` | 빛줄기 |
| | `gfxDust(t, {box, n, seed})` | 떠다니는 먼지 |
| | `gfxGrade(kind, k)` | 색 보정: night · cool · warm · gold · old · dawn |
| | `gfxVignette(k, col)` | 가장자리 어둡게 |
| 말 | `gfxVoice(t, v)` | 지금 그 목소리가 말하는 중이면 `{line, e, u}` |
| | `gfxFace(key, base, t, v, {brow, mouth})` | 말하는 표정(발음 입 + 이·혀 + 눈썹) → `ex:`에 넣는다 |
| | `gfxTalkAct(t, v, seed)` · `gfxListenAct(t, seed)` | 말하는 몸 · 듣는 몸 → `headDy, tilt, sy` |
| 타격감 | `gfxStop(t, [[t0, d, r], …])` | 멈칫: 연기 시계를 잠깐 멈춘다(소리는 흐른다) |
| | `gfxImpact(t, t0, x, y, {col, r, n, flash})` | 충격 프레임 |
| | `gfxSticker(text, {fs, band, peel})` · `gfxSlap(t, t0)` | 스티커(이름 딱지)와 '탁' 붙는 움직임 |
| | `gfxPeel(k)` | 화면이 스티커처럼 넘어가는 전환(0 → 1 덮임, 1 → 2 벗겨짐). `GFR.over`에서 부른다 |
| 자막 | `gfxSubtitle(t, {follow, dim})` | 말을 따라가는 대사 상자. 글자 시각은 줄의 낱말 시각(`TL.lines[i].words`)에서 글자 수 비례로 구한다. 아직 말하지 않은 글자는 `#727C9A`(흰 상자 위 대비 약 4:1). `follow: false`면 처음부터 진하다 |
| 점검 | `gfxMark(name, x, y, r, depth)` · `gfxMarksProject(cam)` | 머리 같은 '잘리면 안 되는 것'을 세계 좌표로 등록 → 그 프레임의 화면 좌표가 `window.GFX_MARKS`에 남는다. r을 `[왼쪽, 오른쪽]`으로 주면 좌우가 다른 것(한쪽으로 날리는 머리띠 끝) |

소리(`gfx_mix.py`): `Mix(dur)` → `.voice(w, t, x, room, wet)` `.sfx(w, t, g, x, room)` `.sfx2(스테레오, t, g)` `.bed(file, t0, t1, g, off)` `.bed_gain(t0, t1, g)` `.amb(kind, t0, t1, rel_db)` `.render(path, margin=12, max_cut=8, stems=…)`. 공간은 room(방) · hall(회의실) · yard(마당). 새 효과음: `printer`(찌익) `slap`(탁) `clack`(철컥) `chirp`(새) `rumble`(굴러옴) `flutter`(팔랑) `gust`(휘이잉, 좌우로 지나감) `creak`(끼익).
- **공기 소리** `.amb('night' | 'office' | 'yard', t0, t1, rel_db)`: 그 구간 배경음보다 rel_db(-13 안팎)만큼 작게 깔리고 배경음과 함께 덕킹된다. 띠는 말소리(300~4000Hz) 아래에 둔다(밤 40~190Hz, 회의실 70~420Hz, 마당 90~480Hz).
- **말 여유 지키기** `render(margin=12)`: 대사 한 줄마다 말소리 띠에서 '목소리 − 배경음'을 재서 12dB에 못 미치는 줄만 그 줄 동안 배경음을 모자란 만큼(최대 max_cut dB) 더 낮춘다. 덕킹은 깊이가 고정이라 음악이 부푸는 대목에서 말이 묻히기 때문이다. 기록은 `M.margin_log`.
- **갈래 저장** `render(stems=경로)`: voice · bed · sfx와 믹스에 실제로 들어간 bedmix · sfxmix를 남긴다 → `mask_*.py`가 읽는다.

## 쓰는 요령
- **주광은 장면에 하나.** 무엇이 빛나는지 먼저 정한다(폰 화면, 창, 해, 등불). 주광 위치는 세계 좌표로 잡고 `gfxProj`로 화면 좌표로 바꿔 넣는다. z는 `기본값 × cam.z`.
- **빛나는 것은 조명 필터 밖에.** 달 · 창 · 화면 · 불꽃은 배경 층이나 번짐 층에 그린다. 필터 안에 넣으면 그늘 색이 곱해져 죽는다.
- **밤 장면의 색 보정은 0.4 안팎.** 더 세게 하면 달과 화면까지 회색이 된다. 번짐(`gfxGlow`)은 색 보정 뒤에 얹는다.
- **필터는 화면 좌표에.** `gfxLayer`와 `gfxCast({cam})`가 알아서 카메라 변환 바깥에 건다. 카메라 변환 안쪽 그룹에 직접 `filter`를 걸면 카메라가 멀리 갔을 때 필터 영역 밖이 잘린다(사갈라 장면에서 겪음).
- **멈칫은 0.06~0.1초.** 그보다 길면 끊겨 보인다. 같은 시각에 `gfxImpact`, `gfxShake`, 효과음(`slap` · `clack`)을 건다.
- **화면 밖에서 말하는 사람**은 구석의 얼굴 창으로 보여 준다(`mlPortrait` 참고). 누가 말하는지 늘 보이게.
- **렌더 시간.** 조명 필터와 그림자가 붙으면 프레임당 0.5~1.4초(없을 때 0.2초. 폰 시점 0.15, 밤 넓은 샷 0.5, 회의실 0.8, 사갈라 1.1, 확대 1.6 이상 클로즈업 1.4). 1막 샘플 3,729프레임이 2코어에서 약 30분, 5분짜리는 1시간 남짓이다. 먼 배경 흐림은 클로즈업에서만 켠다. 작업자 둘로 나눌 때는 뒤쪽(무거운 장면)이 늦게 끝나니 앞쪽이 끝나면 남은 구간을 다시 반으로 나눈다.
- 점검: `milinda01/long/shot_ml.py`의 `--seq t0 t1 n`으로 연속 프레임을 뽑아 움직임을 본다. 렌더가 끝난 뒤에는 `sheet_ml.py`가 프레임 파일로 줄별 시트(시작 · 가운데 · 끝)와 연속 시트를 만든다(브라우저를 다시 띄우지 않아 가볍다).
- **장면은 자막 없이 그리고, 자막은 따로 얹는다.** `render_range.py`는 기본이 자막 없는 판(`ML_NOSUB=1`), `sub_ml.py`가 자막만 투명 그림(1920×260, y 820부터)으로 뽑는다(전체 약 6분). 인코딩: `ffmpeg -framerate 24 -i fr/f%05d.jpg -framerate 24 -i sub/s%05d.png -i mix.wav -filter_complex "[0:v][1:v]overlay=0:820:format=auto[v]" -map "[v]" -map 2:a …`. 자막 문구 · 모양 · 따라가기 방식을 바꿔도 30분짜리 장면 렌더를 다시 하지 않는다.
- **렌더 전에 돌리는 점검 셋(브라우저 화면을 찍지 않아 1~2분).**
  - `edge_ml.py`: 프레임마다 `GFX_MARKS`를 읽어 머리가 화면 왼쪽 · 오른쪽 끝에 0.5~45%만 걸친 채 0.4초 넘게 이어지는 곳을 찾는다(카메라가 옮겨 가며 드러내는 중인 것은 뺀다). 0곳이 될 때까지 샷 키를 고친다.
  - `ML_STEMS=1 build_ml.py` → `mask_ml.py`: 줄마다 '목소리 − 나머지', 낱말마다 '목소리 − 효과음'(6dB 아래면 효과음이 낱말을 덮는 곳).
  - `qa_ml.py`: 줄마다 음성 인식. 통째로 틀리는 줄을 찾는 데 쓴다(아래 '배운 것' 참고).
- 렌더 뒤: `motion_ml.py`가 프레임 차이로 컷 · 컷 길이 · 2초 넘게 멈춘 구간을 적는다(긴 컷에 인서트를 넣을 자리를 찾는다).
- **전/후 비교.** `window.GFX_OFF = 1`이면 빛 · 그림자 · 공기(빛줄기 · 먼지 · 번짐) · 색 보정 · 초점 흐림이 꺼진다(카메라와 연기는 그대로). `ML_EVAL='window.GFX_OFF=1' python3 shot_ml.py 8.1`처럼 같은 시각을 두 번 찍어 나란히 놓는다.

## 1막 샘플을 점검하며 배운 것 (2026-11-22, 같은 실수 금지)
- **샷 키 목록 안에 `//` 주석을 달지 않는다.** 키 여러 개가 한 줄에 있어서, 줄 끝 주석이 같은 줄의 뒤 키를 지운다(문법 오류도 안 난다). 실제로 왕 → 스님 이동과 '휙' 이동이 사라졌었다. 주석은 `gfxCam(` 위에 따로 쓴다.
- **화면 끝에 걸친 조각.** 클로즈업마다 보이는 범위 `[x − 960/z, x + 960/z]`를 계산해 옆 인물의 머리 끝(중심 ± 약 95)이 그 안에 조금만 들어오지 않는지 본다. 아예 다 넣거나(두 사람 샷), 다 뺀다. 이번에 15 · 19 · 31번에서 왕 · 제로 · 스님이 7초까지 걸쳐 있었다. 두 인물 사이가 좁으면 확대를 올려 둘 다 뺀다(19번: 확대 2.2).
- **효과음을 말 뒤로 미룰 때는 컷 시각도 같이 본다.** '탁'을 대사 끝 +0.32초로 미뤘더니 다음 샷으로 넘어간 뒤(0.06초 차이)에 붙어서 화면에서 안 보였다. 탁 시각 < 컷 시각 − 0.2초가 되게 하고, 급하면 컷 대신 짧은 이동(0.4초)으로 넘긴다.
- **클로즈업에서는 도해(꼬리표 · 점선)를 숨긴다.** 넓은 샷에 맞춘 꼬리표가 화면 끝에서 잘리고 얼굴 · 스티커를 가로지른다(28번).
- **넓은 샷과 클로즈업에서 같은 이름표 위치를 쓰지 않는다.** 스님 이름표는 클로즈업(스님 오른쪽)에서는 맞았지만 넓은 샷에서는 화면 밖으로 잘렸다. 샷에 따라 자리를 바꾼다.
- **화면 밖에 뜨는 칩.** 인물 기준 상대 좌표(dy = −700)로 놓은 칩이 화면 위로 나가 점선만 보였다(31번 '생각'). 새 칩은 `gfxProj`로 화면 좌표를 계산해 0~1080 안인지 본다.
- **탈것은 스스로 움직이지 않는다.** 말이 없는 수레가 굴러 들어오는 장면은 이상하다. 끌 것을 그리지 않을 거면 처음부터 세워 두고 카메라 이동으로 등장감을 만든다.
- **말하지 않는 인물의 벌린 입.** 놀란 표정(입 벌림 + 놀람 선)을 다음 대사까지 끌고 가면 그 인물이 외치는 것처럼 보인다(25 · 26번: 딱지 · 왕의 대사인데 제로가 말하는 듯했다). 놀람은 1초 안팎, 그 뒤는 입을 다문 표정으로.
- **도장 · 꼬리표가 옆 인물에 겹침.** 떼어 낸 끌채의 ✕가 왕 머리 위에 걸쳐 왕에게 ✕를 준 것처럼 보였다. 분해도에서 부품이 가는 자리는 인물 머리(중심 ± 95)와 구석 얼굴 창을 피해서 잡는다.
- **복선이 되는 스티커는 붙는 순간 크게.** 넓은 샷에서만 붙이면 글자를 읽을 틈이 없다. 던지는 순간 카메라가 따라가 '탁' 뒤 1초쯤 머문다(11번 '원래 차가운 사람').
- **카메라 길을 바꾸면 '옛 이동이 끝나던 시각'까지 다시 그린다.** 바꾼 키 뒤의 느린 이동(4.5초짜리)이 아직 진행 중이던 프레임은 옛 카메라 상태로 남아 있어 이음매에서 튄다. 다시 그릴 구간의 끝 = max(새 이동 끝, 옛 이동 끝).
- **작은 캐릭터가 공중에 뜸.** 딱지가 가슴 높이에서 스티커를 누를 때 받침이 없었다 → 제로가 손을 내밀어 올라서게 했다.
- **프레임을 /dev/shm에 그리지 않는다.** 30분짜리 렌더를 마친 직후 대화가 멈춰 작업 공간이 다시 켜졌고 프레임 3,729장을 잃었다. 편 폴더의 `fr/`(디스크, gitignore)에 그리면 꺼져도 남고, `render_range.py`가 끝난 프레임을 건너뛰어 이어서 그릴 수 있다. 다시 녹음한 테이크도 그 자리에서 백업한다(`backup_takes.py`).
- **마지막 클로즈업의 머리 위 캐릭터.** 확대 2.25에서는 머리 위 딱지가 화면 위에서 잘렸다. 머리 위에 사는 캐릭터가 있으면 인물 클로즈업은 확대 1.9 안팎이 한계다.

## v2를 만들며 배운 것 (2026-11-22 오후, 같은 실수 금지)
- **머리 반지름은 118·s + 후광 18.** 95로 어림해 손으로 계산했더니 v1에 조각이 여럿 남았고(축소한 시트에서는 안 보인다), 손으로 다시 계산해 고친 뒤에도 도구를 처음 돌리자 넷이 더 나왔다(14번 첫 샷의 스님, 11번의 제로와 팀장, 8번의 제로). 손으로 계산하지 말고 `edge_ml.py`를 돌린다. 한쪽으로 나온 것(왕의 머리띠 끝: 흔들림 + 후광까지 184)은 좌우 반지름을 따로 등록한다. 좌우를 같게 넓히면 반대쪽에서 헛경보가 난다.
- **손도 조각이 된다.** 클로즈업 옆에 선 인물이 그쪽을 가리키고 있으면 손끝이 화면 끝에 동그랗게 걸린다(23번: 스님의 가리키는 손). 가리키는 자세가 이어지는 동안의 클로즈업은 손끝(중심에서 약 200)까지 빼고 잡는다.
- **넓은 첫 샷에서 아직 소개하지 않은 인물.** 카메라가 물러나는 5초 동안 화면 끝에 스님 머리 · 방석 모서리가 걸려 있었다. 뒤에 카메라 이동으로 드러낼 인물은 첫 샷에서 방석 · 소품까지 완전히 뺀다.
- **음성 인식은 '조금 나빠졌는지'를 못 가린다.** 짧은 줄은 잘라 넣는 창을 0.1초만 옮겨도 한두 글자가 뒤집힌다('스님' ↔ '선생님', '바퀴' ↔ '박귀'. v1 · v2를 창 여섯 개로 비교해 둘 다 그런 것을 확인). 믹스를 바꾼 효과는 `mask_ml.py`의 dB로 본다. 원인을 가를 때는 갈래를 따로 인식시킨다(목소리만 → 6/6 '스님', 목소리 + 배경음 → 3/6: 배경음이 원인).
- **효과음이 겹치면 낱말이 묻힌다.** 하나하나는 0.3 안팎으로 작아도 휙 + 띠링 + 톡이 같은 낱말에 모이면 목소리와 2dB 차이까지 온다(`'나'도요`, 마지막 문장의 `없었습니다`). 뜻이 실린 낱말(끝 문장, 반전 한마디) 위에는 소리 하나만, 나머지는 낱말이 끝나는 자리로 민다. 화면 반응도 같이 민다(이름표가 낱말 끝에 '톡').
- **끝 장난은 마지막 문장 뒤에.** 딱지가 스티커를 다시 누르는 장난이 마지막 문장과 겹쳐 있었다. 문장이 끝난 뒤 0.35초에 시작하면 말도 살고 장난도 보인다(끝 여백 3초를 채운다).
- **바람 · 잎 같은 '침묵의 소리'는 침묵 안에.** 0.65초짜리 쉼에 1.6초짜리 바람을 넣었더니 다음 대사 첫머리를 덮었다. 침묵 개그는 쉼 자체를 늘린다(`gen_tl.py`의 GAP 1.55초): 넓은 샷 0.5초 → 얼굴 컷 1초(잎이 지나가고 말줄임표가 뜬다) → 대사.
- **공기 소리의 띠.** 마당 바람을 160~950Hz + 나뭇잎 1400~5200Hz로 깔았더니 말소리 띠 한가운데였다. 바람은 500Hz 아래로, 나뭇잎 같은 높은 소리는 깔지 말고 쉼에만 낱개로 넣는다.
- **한 줄짜리 파이썬에도 줄 끝 `#` 주석 금지.** `a = …; b = …; os.makedirs(…)  # 설명`에서 주석을 중간에 넣으면 뒤 문장이 통째로 사라진다(`render_range.py`가 그렇게 깨졌었다).
- **속 캐릭터의 첫 등장은 크게, 이름이 불릴 때 이름표.** 딱지가 처음 나오는 줄을 중간 샷(확대 1.5)으로 잡았더니 키 90짜리 캐릭터가 화면에서 150px였고, 이름이 불리는 줄에서는 카메라가 오히려 물러나 100px가 됐다. `motion_ml.py`가 '8.9초짜리 컷, 움직임 낮음'으로 짚은 자리였다. 고친 것: 머리 위 클로즈업(확대 2.5) → 던진 스티커를 따라 가슴으로 → "머리 위에"에서 다시 올라가 "딱지"에서 이름표 톡 → 방 전체. 한 컷 8.9초가 네 박자로 나뉜다. 다시 그린 것은 161프레임(2분), 자막은 따로라 손대지 않았다.
- **자막을 따로 얹을 때는 장면의 검은 페이드(처음 0.5초 · 끝 1초)를 자막에도 건다.** 안 그러면 화면이 어두워지는데 자막만 또렷이 남는다(`sub_ml.py`).
