# "보호자분은요?" 엄마와 내가 서로를 쳐다봤다 — 화면 연출 v2 (애어른 편)

대본 `대본_v2.md`와 줄 번호로 맞춘다. 표현 방식은 B 방식(비교 샘플 `cmp/`). 12·13·15·21·22번은 샘플의 길 장면(cmpB)을 다시 쓰고 배경만 AI 그림으로 바꾼다.

## 이번 판의 원칙: 있을 법하게
- 병원 장면은 실제 순서대로만 간다: 입원 수속 창구 → 병실 → 수술실 앞 → 보호자 대기실 → 병실 → 퇴원 수납 창구.
- 인물은 과장된 표정을 쓰지 않는다. 놀람·충격 표정 대신 멈칫, 눈길, 숨으로 연기한다.
- 지어낸 소품(반짝이는 것, 캐릭터 상품)을 쓰지 않는다. 소품은 번호표, 서류와 펜, 만 원짜리 두 장, 보호자 출입증, 전광판.
- 머릿속 길 장면은 대기실 의자에 앉은 제로의 생각으로 들어가고(10~11번 뒤), 전광판이 바뀌는 소리로 나온다(27번).

## B 방식 문법
1. **은유 하나 '문':**

   | 막 | 문의 모습 | 뜻 |
   |---|---|---|
   | 1막 | 서류의 보호자 칸 | 제로 앞에 놓인 낮은 문턱(아직 모른다) |
   | 2막 | 닫히는 수술실 자동문 → 갓의 문 → 일찍 열린 문 → 예식장 문 | 옛날의 어른 되기 |
   | 3막 | 저 멀리 밀려난 문 → 발밑의 문턱 | 지금의 어른 되기 |
   | 4막 | 1995년의 보호자 칸 → 열리는 수술실 문 | 아버지도 넘은 문턱 |

2. **같은 구도:** 12·13·14·15번은 걷는 사람을 화면 왼쪽 3분의 1에 두고 문이 오른쪽에서 다가오는 같은 구도. 3번과 32번, 6번·19번과 24번도 같은 구도로 맞춘다.
3. **숫자는 세는 그림:** 16번. 길 위의 나이 눈금에서 문이 뒤로 밀려난다.
4. **글자는 물건에:** 문의 이름판, 푯말, 말뚝의 꼬리표, 서류의 인쇄 글자, 전광판. 화면 가운데 큰 글자는 25번의 인용 한 번뿐.
5. **문장 뒤 생활 예시:** 17~18번(아넷) 뒤에 19번.
6. **소화 컷:** 9번, 19번, 21번, 26번.
7. **막 끝 요약 띠:** 2막 끝, 3막 끝.

## 공통 규칙
- 기기 화면은 제로 시점에서만. 누르는 손가락은 그리지 않는다. 실존 브랜드·병원 이름·로고 없음.
- 칸트는 뒤로 묶은 머리의 스틱맨 옆모습(다른 인물과 같은 얼굴). 아넷은 이름표만.
- 수술 장면, 피, 주사는 그리지 않는다. 수술실은 닫힌 문과 전광판으로만.
- 13번에 전투 장면·군복·무기를 그리지 않는다(바람에 먼저 열리는 문).
- 색: 병원은 밝은 민트와 흰색, 낮의 창구는 창으로 햇빛. 머릿속 길은 샘플의 밝은 하늘과 살구색 길. 1995년 회상은 살짝 바랜 따뜻한 색(어둡지 않게).
- 배경음: 느린 피아노. 길 장면은 걸음 박자의 가벼운 피아노, 22번에서 따뜻한 현악, 24번은 오르골 같은 한 음씩. 목소리 검사를 통과한 곡만.
