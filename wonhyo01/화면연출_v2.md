# 만약에, 원효처럼 '마음먹기'로 산다면? — 화면 연출 v2 (게임 감각)

`대본_v2.md`와 같은 줄 번호. 실제 장면 코드는 `long/whgf.js`(1~20번), `long/whgf2.js`(21~56번), 표현 도구는 `zw/gf.js`(설명 `zw/GF.md`).

## 지키는 것
- **한 편을 꿰는 표시:** 오른쪽 위 마음 게이지(얼굴 + 막대). 낮으면 얼굴에 뿔이 난다. 같은 문·같은 자리·같은 와인·같은 물에서 게이지만 달라진다.
- **날마다 같은 짜임:** 단계 카드(별 n/4) → 원효 일화(신라 세트) → 제로의 하루 → 연구(실험실 세트) → 제로가 해 봄 → 도장 "n일 차 끝!" + 색종이.
- 무대는 그린 세트(방·문·창·화분·언덕·바다). 인물 대사는 대사 상자 + 이름표. 연구 숫자는 원문에 있는 것만($5·$45, 120곡 중 3곡, 1.5배). 숫자 없는 막대·시소는 크기 비교 그림이다.
- 기기 화면은 보이지 않게(모니터는 뒷면), 누르는 손가락 없음, 채널명은 네온 제목 카드 한 번, 끝인사 없음.
